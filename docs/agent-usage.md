# エージェントの利用状況（トークン・コスト・コンテキスト）

起動しているエージェントの利用状況を、**記録（会話の記録のファイル）から読んで**出します。**Claude Code** の、`sodactl agent usage`・方式 `agent.usage`・ブラウザの**ダッシュボード**（3 つ目の画面。下の「ダッシュボード」）まで。pane の情報ボタン・Codex・Copilot CLI・制限の枠の取り込みは、これから（別の PR）です。調査と、決めたことの理由は `.aidev/works/20261010-agent-usage/`（`research.md`・`decisions.md`）。

## 使い方

```
sodactl agent usage              # 取れる全部
sodactl agent usage <target>     # pane の id か、エージェントの名前
sodactl agent usage --json
```

出るもの（種類 `claude`）:

| 項目 | 中身 |
| :- | :- |
| モデル | 記録の最後の主の応答のモデル名 |
| トークン | 入力（キャッシュの読み書きを含む）・出力。**数え方の印**（下）つき |
| コスト | **記録の会計の行（`cost-state`）があるときだけ**。その行の時点の値（それ以後の分は含まない） |
| コンテキスト | 最後の主の応答の入力側のトークン数。**窓の大きさが分かるときだけ率**（下） |
| 更新 | 記録の最後の応答の時刻 |
| 内訳 | 主のエージェントと、サブエージェント（記録に残る分） |

取れない項目は「—」（`--json` では項目が無い）。**0 とは違います**。

## ダッシュボード（画面）

ブラウザの**サイドバーの上の切り替え**（基本画面／グラフ／**ダッシュボード**。狭いサイドバーでは「ダ」）で開く、3 つ目の画面です。**見るだけ**です（数字を出すだけで、エージェントには何も送りません）。

- **上部: アカウントの利用枠**。種類（Claude Code・Codex…）ごと・枠（5 時間・週…）ごとの使用率の棒と数字、リセットまでの時間（「あと 2 時間 10 分でリセット」）、値の時刻（「3 分前」）。**値が無いときは、小さく「まだ値がありません」**（今の版は、制限の枠を取り込む前なので、いつもこの表示です。ステータスラインの包み〔PR2〕と Codex の記録の取り込みで出ます）。リセットの時刻を過ぎた枠は、率を出さず「リセット済み（次の値を待っています）」と薄く出します。
- **一覧**: 起動しているエージェント 1 つが 1 行です（エージェントの居ない pane は出ません）。状態・種類・名前・モデル・場所（workspace／tab・作業フォルダ・ブランチ）・サブエージェントの数・トークン・コスト・コンテキスト・最後の動き。
  - **トークン**は、**数え方の印**（累計／記録分〔記録に残る分。確定した累計ではない〕）と、読み込み中・一部の印つき。**コスト**は、時点つき（記録の会計の行の時点「N 分前の時点」・報告の見積り）。無いものは「—」です（0 とは書きません）。
  - **コンテキスト**は、率が分かるとき棒と数字、分からないときはトークン数だけ。棒は数字を併記します（色だけに頼りません）。
  - **古い値**（更新が 1 分より前・更新が止まった）は薄く出し、時刻（「N 分前」）を添えます。
- **並べ替え**（状態・コスト・トークン・名前）と、**種類の絞り込み**。並べ替えはブラウザに覚えます。
- **行を押す（Enter）と、その pane へ移ります**（基本画面に切り替えて、その workspace・tab・pane を選びます）。行へは ↑↓・Home・End で移ります。`Esc` か `prefix`+`a` で基本画面へ戻ります。
- **別のマシン**: 画面が向いているマシン（サイドバーで選んだもの）の pane だけを出します。別のマシンへ切り替えれば、そのマシンの分が出ます（そのマシンのサーバが読みます）。そのサーバが古く、利用状況に対応していないときは、その旨を出します。
- **端末へのキーは届きません**: ダッシュボードの画面が出ている間、基本画面の端末は見えない（`inert`）ので、キー入力は端末へ送られません（グラフの画面と同じ決まり）。`prefix` の二度押し・分割・閉じる操作などは食います。画面を切り替えても、端末（PTY）の大きさは変わりません。
- **様式**: クラシックは端末らしい表（罫線の行）、モダンは行がカード（角の丸い面）。色は画面のテーマの色です。
- **1 列の画面（モバイル）**: 重ねる全画面のダイアログです（行は縦のカード・押せる部品は 44px）。入口は、pane のピッカー（上部の workspace／tab の表示を押して開く）の一番下の「ダッシュボード」と、全体のメニュー（クラシック）です。行を押すと、ダイアログを閉じてその pane へ移ります。

### 更新の配信

ダッシュボードが**見えている間だけ**、サーバが 5 秒おきに利用状況を確かめ（記録が変わっていなければ読みません）、変わった分を `agent.usage_changed` で、**見ている接続にだけ**送ります。

- ブラウザは、ダッシュボードが見えていて・タブが前面で・接続が開いている間だけ `agent.usage_watch {on: true}` を送ります。見えなくなる・別の画面へ移る・タブが裏へ回るで `on: false`。接続が切れたら、サーバの印も消えます（開き直したら送り直します）。見ている接続が 1 つも居なければ、サーバは確かめません（タイマーも止まります）。
- 画面に出る間隔は 5 秒＋記録の書き込みの遅れ。**エージェントが動いていない間は、値は変わりません**（古い値は薄く出ます）。
- 配るのは `agent.usage` の答えと同じ形（数字・モデル名・時刻・ラベルだけ）の差分です。`pane.sock` には載せません。`sodactl` など画面を持たないクライアントには、頼まれない限り送りません。

## 数え方の印（確定した累計とは言いません）

- **累計**（`cumulative`）: Claude Code が記録の区切り（`/clear`・終了・再開）に書く会計の行（`cost-state`。未文書）の累計に、その行より後の記録の分を足したもの。コストも、この行の値です。
- **記録に残る分**（`transcript`）: 記録の応答の `usage` を、応答の id ごとに 1 回数えた合計（サブエージェントの記録を含む）。**会計の累計より小さく出ます**（調査で、出力トークンが 1/3〜1/9 になる例を確かめました。記録に残らない呼び出し・消えたサブエージェントの記録などが理由と考えられますが、確かめていません）。下限として読んでください。
- **一部**: 大きな記録（64 MiB 超）は末尾の 64 MiB だけを読みます（初めの分は含まれません）。サブエージェントの記録が 256 を超えたときも「一部」です。
- **読み込み中**: 大きな記録は、背景で何回かに分けて読みます。もう一度呼ぶと増えます。

## 出ないもの・限界

- **コストの単価の表は持ちません**。コストは `cost-state` の行があるときだけです（動いている間は更新されない: 区切りにだけ書かれます）。ステータスラインの報告（`cost.total_cost_usd`）からのコストは、PR2 で足します。
- **制限（5 時間・週）の使用率とリセットの時刻**は、記録に出ないので、まだ出ません（Claude Code は PR2 のステータスラインの包み。Codex は記録から）。ダッシュボードの上部の枠は、それまで「まだ値がありません」です。
- **コンテキストの使用率**は、窓の大きさが記録に出ないので、モデルの id に `[1m]` が付くとき（100 万）だけ出ます。ほかは、トークン数だけ。
- `cost-state` は公式の文書に無い内部の行で、**版で形が変わりえます**。読めなければ、黙って「記録に残る分」へ落ちます。
- **応答の `usage` は、同じ id の最初の行を取ります**（実在の記録では、同じ id の行の `usage` は同一でした。将来の版で、後の行が確定値になれば、過小に出ます）。
- **サーバと pane の `CLAUDE_CONFIG_DIR` が違うと**、記録の場所が根の外になり、読まれません（黙って「無い」になります）。サーバを起動した環境に、pane と同じ値を渡してください。
- **`cost-state` は、サブエージェントの記録が遅れて書かれたとき**（行の時刻は前、書かれたのは後）、その後の分に入らず、わずかに過小になります。会計の累計（`cumulative`）は、記録の合計より大きいのが普通で、そちらを優先します。
- **プロジェクトのフォルダが 5,000 を超える**根では、探索が黙って打ち切られます（記録が「無い」扱いになることがあります。フックの報告の場所が合えば、探索はしません）。
- **同じ会話の id が複数のプロジェクトにある**とき（別のフォルダで再開すると複製ができます）は、更新の時刻が新しいほうを読みます。
- **1 つの会話で読む量の生涯の上限（512 MiB）**に達すると、その会話の更新を止め、数字は止まった時点のもの（`partial` と `updatesStopped`）になります。記録が書き換えられて数え直しになっても、読んだ量は引き継ぎます。
- 利用者が付けたセッションの名前・会話の文・記録の場所は、答えのどこにもありません。

## 安全

- 入力は pane の id だけ。**記録の場所は受け取らず、サーバが決めます**: pane の会話の id（フックの報告をサーバが受け入れたもの）から、記録の根（`~/.claude/projects`・`CLAUDE_CONFIG_DIR` の `projects`）の直下の 1 段の中の `<会話の id>.jsonl` だけを読みます。フックの報告の場所（`transcript_path`）は候補にするだけで、実体のパスが根の下・名前が一致・リンクでない通常のファイル・リンクが 1 つのときだけ使います。合わなければ、根の下を会話の id の名前で探します。
- サブエージェントの記録も、`<会話の id>/subagents/agent-*.jsonl` の決まった形で、実体のフォルダが組み立てた場所と一致するときだけ。
- 開くときは `O_NOFOLLOW`・`O_NONBLOCK`（FIFO で固まらない）で、開いた fd で通常のファイル・リンク 1 つを確かめ直します。サブエージェントの記録の窓（`agent.subagent_transcript`）と同じ部品です。
- **記録の場所は、受け入れた報告のものだけ**覚えます（会話の参照の確かめを通った報告。保留の後で受けた場合も）。捨てた報告（子のエージェント・別の pane・Codex の常駐のプロセス）の場所・実在しない pane の報告は覚えません。
- モデルの名前は、先頭が英数字で、英数字と `.`・`_`・`-`・`:` と末尾の `[1m]` の類だけを通します（それ以外は「—」）。
- pane が閉じたとき・サーバが止まる処理に入ったとき、走っている読みはチャンクの境目で止まります。同じ pane への同時の呼び出しは、場所の探索を 1 回にまとめます。
- ログイン済みの `/ws` の方式だけ（`pane.sock` には載せません）。別のマシンの pane は、そのマシンのサーバが答えます。
- **フックのスクリプトが変わりました**（会話の記録の場所を報告に添えます）。導入済みの方は、設定の「エージェント連携」に「更新が必要」と出ます。押したときだけ書き換わります。更新するまでは、記録の場所を探索で見つけます（少し遅くなりえます）。
