# キャラクター素材の取り込み形式

デスクトップアシスタントは、PNGの立ち絵と、任意の表情・ポーズ差分を取り込めます。特定の制作アプリは不要です。素材を用意するときは作者の利用条件を確認してください。取り込みは画像とJSONを読むだけで、同じフォルダのプログラムを実行しません。

| 形式 | 設定画面の操作 | 内容 |
| --- | --- | --- |
| 素材フォルダ | キャラクター素材フォルダを読み込む | `casts.json`、`chars/<id>/normal.png`。任意で出典メモと表情・ポーズ差分 |
| `.sodaplugin` | 素材パックを選んで確認 | パッケージの`assistantCharacters`で指定した静止PNG |

どちらもプレビュー後に「この素材パックを追加・置き換え」を押し、「追加キャラクター素材を表示する」を有効にして、立ち絵を選んで保存します。取り込みだけでは表示中の立ち絵を変更しません。

## 素材フォルダの最小構成

次の`my-characters/`を選択します。PNGファイル単体を直接選ぶ形式ではありません。

```text
my-characters/
├── casts.json
├── chars/
│   └── guide/
│       └── normal.png
└── recipes/                 # 任意
    └── guide.json           # 任意：出典・作者のメモ
```

`casts.json`はキャラクターIDをキーとするJSONオブジェクトです。表示名に`name`を使います。他の設定項目は立ち絵の取り込みには不要です。

```json
{
  "guide": { "name": "案内役" }
}
```

IDは小文字英数字で始まる1〜64文字で、小文字英数字・`_`・`-`が使えます。フォルダ名とJSONのキーを合わせます。名前が未登録の場合はIDを使います。`guide_alt`のように`_`を含むIDは、完全一致する登録がなければ先頭部分の`guide`から名前を取得し、バリエーションのIDを併記します。

出典を残す場合、`recipes/guide.json`の`_comment`に書きます。最大2,000文字を設定画面のプレビューへ表示します。

```json
{
  "_comment": "作者：作者名 / 配布元：素材の配布ページ / 利用条件：同梱の利用規約を参照"
}
```

### 静止PNGの上限

- 入力は1ファイル8MiB以下、幅3,840px以下・高さ2,160px以下のPNG。透過PNGを推奨します。
- `chars/`直下は256項目以下、1回の取り込みは最大64キャラクター、入力PNGの合計は64MiB以下です。
- 取り込み時に透明余白を詰め、縦横比を保って最大辺512px・128KiB以下へ変換します。元ファイルは変更しません。
- `normal.png`がないキャラクターは警告してスキップします。JSONは1ファイル1MiB以下、トップレベルは最大256キーです。
- 通常のファイル・フォルダを使います。素材ファイルやキャラクターフォルダのシンボリックリンクは使えません。

フォルダ取り込みは専用の1つの素材パックを追加・置き換えます。別々の素材フォルダを順に取り込んで独立したパックとして残す形式ではありません。複数パックを分けたい場合は、後述の`.sodaplugin`を使ってください。

## 表情・ポーズ差分（任意）

静止PNGに加えて、キャラクターごとに`sprite.json`と`sprite/`を置くと、素材にある表情やポーズを切り替えられます。

```text
chars/guide/
├── normal.png
├── sprite.json
└── sprite/
    ├── aaaaaaaaaaaa.png     # ポーズの基準画像
    └── bbbbbbbbbbbb.png     # まばたきの置換パーツ
```

最小の差分定義例です。例の識別子に対応するPNGを実際に用意してください。

```json
{
  "w": 300,
  "h": 500,
  "source": "作者・出典のメモ",
  "poses": {
    "": {
      "base": "aaaaaaaaaaaa",
      "faces": {
        "normal": { "blink": ["bbbbbbbbbbbb", 110, 70] }
      }
    }
  }
}
```

- `w`・`h`は共通の描画範囲で、各1〜1,024px。各ポーズの基準PNGはこの幅・高さと一致させます。標準ポーズのキー`""`は必須です。
- ポーズは`""`（標準）、`chin`（考える）、`point`（指差し）、`raise`（腕上げ）に対応します。
- 表情は`normal`・`smile`・`think`・`surprised`に対応します。表情ごとに`e`（表情の上書き）、`blink`（まばたき）、`open`（開き口）、`half`（半開き口）を任意で指定します。
- 各パーツは`[画像ID, 左位置, 上位置]`。位置は0〜1,024の整数で、パーツ全体を描画範囲内に収めます。基準画像、`e`、まばたき、口の順に描画します。
- 画像IDは12〜64文字の小文字16進数で、ファイル名は`<画像ID>.png`です。1キャラクター最大96画像、各差分PNGは512KiB以下、取り込むPNG合計は3MiB以下。保存するJSONを含めた1キャラクターは4MiB以下です。
- 表情素材の1回の取り込み合計は64MiB以下、保存領域全体は128MiB以下です。差分のない素材は静止PNGで表示します。

ポーズや顔を新たに生成する機能ではありません。素材の基準画像や置換パーツを用意する必要があります。口の切り替えは音素に同期した口パクではありません。

## `.sodaplugin`で静止PNGを配布する

素材パッケージの`soda-plugin.json`に`assistantCharacters`を宣言し、PNGを`files`に含めます。

```json
"assistantCharacters": [
  { "id": "guide", "name": "案内役", "file": "assets/guide.png" }
]
```

パッケージを作るコマンドは次のとおりです。マニフェスト全体の書式は[配布できる拡張パッケージ](plugin-packages.md)を参照してください。

```sh
sodactl plugin pack /path/to/character-pack --out characters.sodaplugin
```

この経路のPNGは1,024×1,024px・128KiB以下で、フォルダ取り込みのような自動縮小は行いません。静止画像の保存領域は両経路で共通です。最大16パック・128キャラクター・8MiBです。配布用の`.sodaplugin`に宣言できるキャラクターは1パック最大8件で、フォルダ取り込みの最大64件とは異なります。この操作で取り込むのはキャラクター素材だけで、パッケージにプログラムが含まれていても有効化・実行しません。

## 対応しない形式

PSD・SVG・JPEG・WebP・GIF・動画を直接取り込むことはできません。PNGへ書き出してから上記の構成へ配置してください。音声モデルや音声設定はこの取り込みに含めず、ボイス設定で別途指定します。
