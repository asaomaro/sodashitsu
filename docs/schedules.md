# 処理の予約

サイドバー上部の画面切替は「端末・グラフ・状況・予約」です。「予約」でエージェントへの指示、またはワークスペースでのコマンド実行を登録できます。Web版と端末版は同じサーバーの予約・実行履歴を使います。

「予約を登録」で名前、実行内容、対象、実行日時を指定します。一回実行のほか、開始日時と分単位の間隔による繰り返しを選べます。コマンドのカレントは対象ワークスペースのPJフォルダ（未設定ならワークスペースの起動フォルダ）です。実行の上限時間も指定できます。予約の一覧から編集、有効・無効の切替、削除、今すぐ実行ができます。削除しても実行履歴は残ります。

実行履歴には指示・コマンド本文、開始・終了日時、結果、コマンド出力と終了コードが表示されます。エージェントの「指示送信済み」は入力を送った結果です。エージェントが作業を完了したことは意味しません。対象エージェントが終了している、承認待ちであるなど、送信できない場合は失敗として記録します。

端末版ではサイドバーの「予約」を押し、`n`で登録、`Enter`で編集、`Space`で実行履歴、`x`で今すぐ実行、`e`で有効・無効を切り替えます。編集画面は`Tab`で欄移動、選択欄は左右キー、本文は改行・貼り付け可能、`Ctrl+S`で保存します。`Esc`で一覧、さらに`Esc`で端末へ戻ります。

予約はサーバーが動作している間に実行され、`state-dir/schedules.json`に保存されます。繰り返しの実行日時を過ぎて再起動した場合、積み残しをまとめて実行せず次回へ進めます。同じ予約は重複して実行せず、同時実行は4件、登録は128件、履歴は最大500件です。履歴出力は1件8,192文字までです。終了・handoff時の実行中処理は中断し、再起動時に自動で再実行しません。

内部RPCは `schedule.list`、`schedule.save`、`schedule.remove`、`schedule.run` です。Web/TUIの通常の認証済接続で呼び出します。
