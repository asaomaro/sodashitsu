# デスクトップアシスタント（開発中）

操舵室のWindows用ネイティブ補助アプリです。Soda本体やエージェントはWSLで動かし、アシスタントはWindowsのデスクトップに表示します。現時点は常駐表示と設定の基盤です。通知やチャットの完成版ではありません。

## 実装済みの基盤

- 無効を初期値とする有効・無効の設定、設定ファイルへの保存と復元。
- 男性船長・女性船長・ロボット船長の標準素材。大きさと表示モードを切り替えられます。
- 画面右下のキャラクター、または通知領域のアイコンのみの表示。どちらでもアイコンのメニューから設定・終了を選べます。
- キャラクターをクリック、またはアイコンの「船長と話す」から吹き出しを開きます。キャラクター自体はキーボードフォーカスを奪いません。
- 吹き出しの初期画面。「専用セッションに接続すると会話できます」と表示し、接続機能の実装前は送信を無効にしています。
- 「操舵室を開く」で通常の操舵室画面を別窓に開きます。既存のターミナル・質問フォームを使えます。これは専用アシスタントセッションではありません。
- Windows配布版でのみ、明示的にログイン時の起動を設定できます。開発版での設定や非Windowsでの有効化はエラーにします。

接続先は `http://127.0.0.1:7780` などローカルHTTP、またはHTTPSのオリジンです。パス、URL内の認証情報・トークン、LANへの平文HTTPは受け付けません。TLS証明書の検証を省略しません。操舵室のログイン画面で認証します。設定JSONにトークンは保存しません。

## 開発時の起動

WindowsのNode.js 24以降とpnpmを使い、Windows側で依存を導入・ビルドします。WSL側の `node_modules` との共用は避けてください。

```powershell
pnpm install --frozen-lockfile
pnpm --filter @sodashitsu/desktop-assistant build
pnpm --filter @sodashitsu/desktop-assistant start
```

`--ignore-scripts` で導入した場合、Electron本体のダウンロードが行われていないため、そのままでは起動できません。`pnpm build` や `soda handoff` は、このアプリをデスクトップに起動する操作ではありません。

Windows用zipのビルドは `pnpm --filter @sodashitsu/desktop-assistant pack:win` です。現段階は署名なしの開発配布設定です。署名・配布手順とWindows実機での起動確認は未完了です。設定はElectronのアプリ別userData内の `assistant.json`、ログイン状態は別のElectron sessionに保存します。アプリを無効にするとキャラクター・吹き出し・操舵室窓を閉じ、設定と終了のため通知領域アイコンは残します。

## 後続で実装するもの

通知は記号だけでなく、吹き出しの言葉で伝えます。専用チャットと通知元への返答も吹き出しで行い、送信先を表示します。トレイモードでも会話できます。長いターミナルや質問フォームは吹き出しから展開します。

専用エージェントの常駐・再接続、認証済み通知の配送・通知元への返答、吹き出しでの会話、OCR、プラグインキャラクター・UI・機能の導入は後続です。文字起こし（マイク・音声ファイル）、読み上げ、選択文の要約・翻訳、メモ、既存予約機能を使ったリマインダーも追加対象です。録音や画面取得、外部サービスへの送信は明示的に行う構成にします。

## 確認

```sh
pnpm exec vitest run --project @sodashitsu/desktop-assistant
pnpm --filter @sodashitsu/desktop-assistant verify:ui
```

前者はOSを呼ばない注入アダプターと一時ファイルを使います。後者はPlaywright Chromiumの導入が必要なヘッドレス生成UI検証です。実際の画面・マイク・クリップボード、ログイン時起動の登録、実エージェントの起動は行いません。Windows実GUIとLinux/macOS実機は別途確認が必要です。
