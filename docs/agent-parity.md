# エージェントの共通対応

Claude Code（claude）、Codex（codex）、Muse Code（muse）、Antigravity CLI（agy）、GitHub Copilot CLI（copilot）を、次の共通機能で扱います。

| 共通機能 | 対応 |
| --- | --- |
| pane/グラフからの起動、前面検出、状態表示 | 5種類 |
| 専用デスクトップ会話とモデル・effort設定 | 5種類。CLI/モデルの許す値だけ使用 |
| 作業一覧、確認待ち・完了通知、発信元と直近の応答 | 5種類。記録未取得なら状態と発信元を表示 |
| 専用端末、ask-formのみの小窓、操舵室への切替 | 5種類。フォームはsodactl askを利用 |
| 監督役・配下・グラフの連携 | 5種類。入力待ちを確認して送信 |
| 会話、過去一覧、UUIDで再開、要約、作業文脈 | 5種類。既知の保存先と確認済み会話だけ読む |
| ライブ利用量、期間履歴、比較、親子/ツール分析 | 5種類。記録で確認できた数値と関係だけ表示 |
| 分析レポートの生成、HTML表示/出力 | 5種類。明示的な生成や自動要約ではモデルを利用 |
| サーバ上のプラグイン作業エージェント | 5種類。新しいpaneで起動 |

## CLIごとの記録と限界

- Claude Code/Codexは従来の記録と設定を継続します。
- Muse Code 1.4.14-R7309.1では、Linux/WSLのSessionStartフック・UUID再開・ローカルecho・MSP read/forkを確認しています。報告済みprovider usageだけを集計します。読み取り専用MSPでツールの投影を補う場合もモデルは呼びません。詳細は[専用文書](muse-code.md)。
- Antigravity CLI 1.4.12では、隔離した実CLIの短い応答とファイル読み取りでtranscriptの形式を確認しています。完了PLANNER_RESPONSEの数値とtool_callsを使います。履歴にモデルや親子関係が無い場合は未取得です。statuslineのコンテキスト率や制限枠は消費量とは別です。
- GitHub Copilot CLIはこの環境を、利用者の同意により0.0.362から1.0.105へ更新しました。古い0.0系には現在のフック/SDK/effort機能が揃わないため、現行1.xを使用してください。AIクレジットをUSDへ換算しません。

## 固有の操作

ネイティブ会話forkはClaude Code・Codex・Muse Code・Copilotに対応します。Antigravityには検証済みの同等APIがないため表示しません。画像をモデルへ直接渡すデスクトップ機能はClaude/Codex、専用の音声入力APIはCodexが対象です。ローカルOCR/Whisperによる文字化から通常会話へ送る経路は種類に依存しません。

接続先に操作範囲を固定するwork agentの操作元起動・ネイティブ会話転送はClaude/Codexの検証済み経路を維持します。任意のCLIへ既存のセキュリティオプションを流用したり、会話ファイルを推測で書き換えたりしません。サーバ上の通常の作業pane起動とは別の機能です。

ToDoはCLIが保存する認識可能なsnapshot/planだけを表示します。形式が無い・取得できない場合は説明を表示し、完了0件とは扱いません。ツールの結果や親子関係が記録されない場合も未取得です。

Antigravityによる自動要約/レポート実行はLinuxのbubblewrapで利用者のhomeを一時設定領域へマウントして実行します。OSのhome変数や元の設定は変更せず、認証と許可したモデル設定だけを引き継ぎ、グローバルフック・プラグインを持ち込みません。モデル以外のツール操作も拒否します。bubblewrapを使えない環境では、この自動実行だけ理由を表示して停止します。通常の対話起動・監督・データ分析は継続できます。

## statuslineの情報

公開された数値を共通表示へ統合しています。CLIによって報告項目は異なります。Copilotの累計・文脈・AIC、Antigravityの報告コスト・effort・残量、MuseのMSP文脈と正規化済み累計・契約枠は[利用状況の追加情報](agent-usage.md#ステータスラインの追加情報)を参照してください。未報告項目まで同じ値が取れるという意味ではありません。

## 専用会話の復元で確認する情報

5種類とも、保存した専用セッションの所有情報に加え、現在のエージェントinstanceに結び付くフック、または実際の前面CLIの明示的なUUID再開引数を照合します。Claudeの`--resume`/`-r`、Codex/Museの`resume <UUID>`、Antigravityの`--conversation`、Copilotの`--resume`が対象です。MuseはUUIDv7に限定します。会話名、最新の会話、選択画面、プロンプト文字列、ツールが起動した子エージェントから会話IDを推測しません。ラッパーと本体でIDが競合する場合も採用しません。clear/fork後の会話変更はフックで追跡します。

2026-11-07に、Claude・Muse・CopilotでUUID再開後にフックより先に専用会話を復元できない経路を修正しました。5種類の保存/復元と送信直前の対象確認はfixtureで検証しています。各CLIでモデルを呼ぶ実会話往復の検証とは区別します。
