# リソースモニター

サイドバー上部の「その他」から「リソースモニター」を選びます。モバイルでは上部の「その他」から開けます。

接続先サーバのCPU・メモリと、操舵室サーバ、関連プロセス、端末、エージェントのプロセス別CPU・RSS・スレッド数を表示します。paneの端末PIDと子孫から作業名を付けます。サーバの子孫と、引き継いだpaneのプロセスが対象です。無関係なPC内の全アプリは収集しません。コマンドライン・環境変数は表示・転送しません。

対応するデスクトップアシスタントは、アプリ本体・描画・GPU等のElectronプロセスを報告します。WSLサーバとWindowsアプリのようにOSが異なる場合も、接続元とOSを分けて表示します。同一OSではホスト／PID名前空間のハッシュとプロセスの開始情報が一致した行を統合します。照合できない行は別々に残します。生のマシン識別子は転送しません。

3秒ごとに更新し、CPU・メモリの直近60回の推移を表示します。検索、対象の絞り込み、CPU・メモリ・名前の並べ替え、更新の一時停止が使えます。画面を閉じるかブラウザを非表示にすると定期要求を停止します。アプリの収集要求は最後の画面要求から12秒で失効し、報告は15秒で失効します。

ホストCPUは全コア合計を100%とし、プロセスCPUは1コアを100%として表示します。初回・取得不能は「—」です。画面上部に操舵室関連だけのCPU合計・メモリ合計（RSS）・プロセス数を表示します。サーバが照合・統合した一覧の全対象を一度ずつ集計し、別OSの対応デスクトップアプリも含みます。検索・対象の絞り込みでは合計は変わりません。取得不能は0にせず合計から除き、取得済み件数を表示します。全件取得不能は「—」です。CPU合計も1コア100%のため100%を超える場合があります。RSS合計には共有ページの重複があるため、ホスト全体の使用メモリとは一致しません。ホスト全体のCPU・メモリは別のカードに表示し、別OSのアプリメモリはホストの使用量には足しません。

Linuxは/proc、WindowsはWin32_Process、macOSはpsから取得します。終了したプロセスの行は次回の収集で消え、PIDが再利用された場合はCPU差分をリセットします。収集権限がない情報は空欄または取得失敗として表示します。古いサーバはこの画面のAPIに未対応です。
