# 画面の様式（クラシック／モダン）

ブラウザ版の設定の節「表示」の、ラジオ「画面の様式」で選ぶ（再読み込みは要らない。同じ利用者の別のブラウザにも反映される）。値は共有の設定の `uiStyle`（`"classic"` か `"modern"`。無い・読めない値は `classic`）。

- **クラシック**: いまの見た目。何も変わらない（比べる道具で、画素まで同じことを確かめている。`docs/verification.md`「画面の見た目を、変更の前後で画素まで比べる」）。
- **モダン**: 角を丸く、行・押せる部品の高さと左右の余白にゆとりを持たせ、pane の間のすき間を広げる。**色と文字（`font-family`）は、様式で変えない**。

## いまの段階でモダンが変えるもの（PR1c・PR2・PR3）

| 所 | モダンの値（**仮置き**） | 決めてある場所 |
| :- | :- | :- |
| 角（小・中・大） | 6・8・12px（クラシックは 3・4・6px） | `packages/web/src/styles/uiStyle.css` |
| pane の間・外周のすき間（設定「pane の枠・隙間の太さ」の 3 段） | 細い 4px・既定 8px・太い 12px（クラシックは 2・4・6px） | `packages/web/src/store/settings.ts` の `PANE_FRAME_THICKNESS_PX_BY_STYLE` |
| pane の枠（選択の強調・薄い枠・ドロップ候補）の角 | 大きい角（12px） | `uiStyle.css` の `--soda-shape-pane-radius` |
| 重なる部品（右クリックのメニュー・表示の面のメニュー・各種ダイアログ・トースト・再接続の表示）の**影** | `0 8px 24px` と `0 1px 3px`（黒を 22%・18% 透かした色。明るいテーマでも濃すぎない） | `uiStyle.css` の `--soda-shape-shadow`（クラシックは影なし） |
| ダイアログの内側の余白・メニューの角と上下の余白 | 20px・角 8px・上下 6px | `--soda-shape-pad`・`--soda-shape-menu-radius`・`--soda-shape-menu-pad-y` |
| 重なる部品の中の押せる部品（ボタン・入力・メニューの行・設定のスイッチとラジオ・トースト）の高さ | 32px 以上・メニュー・トーストの左右の余白 12px | `--soda-shape-control-h`・`--soda-shape-pad-x` |
| サイドバーの行・tab・「＋」・画面の切り替え・サイドバーの下のボタン | 行 36px・押せる部品 32px 以上・左右の余白 12px | `uiStyle.css` の `--soda-shape-row-h`・`-control-h`・`-pad-x` |
| サイドバーの区画の見出し（spaces・agents）と並び順の表示 | 行の 0.95 倍の大きさ・濃さ 0.9（クラシックは 0.85 倍のボタンの中の 0.85 倍＝実効 0.72 倍・濃さ 0.75） | `--soda-shape-section-font`（ボタン）・`-inner`（ボタンの中の題・印・件数）・`-opacity`（モダンだけ） |
| サイドバーの、選んでいる workspace の行 | 角の丸い枠（accent・1px）・accent を薄く混ぜた地・左右に 6px の内側の余白（クラシックは今の行いっぱいの塗り） | `--soda-shape-row-inset`・`-row-radius`・`-row-current-ring`・`-row-current-tint`（モダンだけ。部品の側が `var(--x, 今の値)`） |

- 数値は、**`uiStyle.css` の 1 か所と、太さの表の 1 か所**に集めてある（後から変えやすい）。クラシックでは、高さ・余白・pane の枠の角のトークンを**定義しない**（部品の側が `var(--名前, 今の値)` の形で読むので、未定義＝今の値）。
- **いまある 4 つの設定（pane の枠の表示・隙間・隙間の太さ・外周の枠）は、モダンでも、今と同じ意味で効く**（太さの値だけが、様式の表で替わる）。
- pane の角は、すき間の 1.5 倍までに抑える（細い 4px のすき間で、端末の四角い角に重ならないように。`--soda-shape-pane-radius-per-gap`）。
- 端末の桁と行は、すき間・高さの分だけ変わる（箱が変わるため）。様式を切り替えると、端末の大きさが変わった知らせが 1 回ずつ送られて落ち着く。分割の比率・端末の文字の大きさは変わらない。

## モダンの配置（PR4）

モダンのときだけ、部品の**置き場所**を変える。**クラシックは、配置も 1 画素も変えない**。出し分けの判定は、`composables/useUiStyle.ts` の 1 つの口（`modernLayout`。モダンで、かつ 1 列のモバイルの画面でないとき）に集めてある。様式を切り替えると、再読み込みなしで配置が替わり、フォーカスが消える部品の上にあったときは、対応する新しい部品へ移る（対応が無ければ端末）。

| 所 | クラシック | モダン |
| :- | :- | :- |
| メニューの「連携（グラフ）」（全体のメニュー） | 出す | 出さない（サイドバーの上の「基本画面／グラフ」の切り替えと、キー `prefix+a` で足りる） |
| サイドバーをたたむ・広げる | 最下部の［«］［»］ | サイドバーと主な領域の境の線の縦の中央に、小さな丸の印（押せる当たりは 24px）。たたんだ状態でも同じ縦の中央（畳んだ nav の内側の右端。外へはみ出すと切られるため）。幅のつまみの上にあるので、**印の上では幅のドラッグが始まらない**（つまみの別の場所は、今までどおり）。つまり、縦の中央の 24px 分は、幅をドラッグで変えられない（印の上下は変えられる）。畳んだ状態では、行の印に重ならないよう、当たりを右の 18px に絞る。主な領域の左端 12px（境の両側 12px ずつ）を、縦の中央で覆う |
| ［新規］［メニュー］ | spaces の区画の下 | サイドバーの最下部。通知のベルと並ぶ（左から［新規］［メニュー］・右端にベル）。たたむと縦に並び、印だけ（読み上げの名前は保つ）。メニューは、ボタンの上に開く |
| ［新規］を押したとき | workspace を作る | 小さなメニュー: **workspace**（今の「＋新規」と同じ）・**pane**（いまの tab を右へ分割。`split_vertical` と同じ向き。グラフの画面では出さない）・**グループ…**（**いま開いている workspace** を入れた新しいグループを作る。名前のダイアログ。ほかの workspace の行でグループを作るには、先にその workspace を開く）。キーボードで選べる |
| workspace の行の右クリックの「新しいグループを作る…」 | 出す | 出さない（［新規］から作れる。グループへ追加・移す・外すは残る） |
| tab バー | tab が 1 つだけのときは隠す | 1 つのときも出す（tab と「＋」）。位置（上・下）の設定は、どちらでも効く |

- 新しい操作（サーバの方式）は作っていない。［新規］のメニューは、今ある操作（workspace を作る・pane を分割する・グループを作る名前のダイアログ）を、新しい場所から呼ぶだけ。
- tab バーが出ると、端末の行が減る。様式の切り替え・tab の数の変化のとき、`client.view` は pane ごとに 2 回以内で落ち着く（E2E `ui-style-layout.spec.ts`）。
- 限界: モバイルの 1 列の画面（`MobileShell`）は、この配置を使わない（骨組みはクラシックのまま）。サイドバーをたたんだ状態の印は、畳んだ幅（3em）に収めるため、境の線の上ではなく内側の右端に置く。

## pane の操作ボタン（モダンだけ）

基本画面の pane の枠に、［右へ分割］［下へ分割］［最大化／元に戻す］［閉じる］のボタンが付く（この順。閉じるは、いちばん右で、ほかと少し間を空ける）。**クラシックでは出ず、名前の行の高さも今のまま**。

- **置き場所**: pane の名前の行が出ているとき（設定「表示」の「pane の名前」が入で、枠が出ているとき。名前が空でも、行は確保される）は、その行の右端（行の高さはモダンで 28px。`--soda-shape-name-h`）。名前の行を出さない設定のときは、端末の領域の右上の隅に重ね、**その pane にポインタが載っている間・pane が選ばれている間・ボタンにフォーカスがある間だけ**出す（隠れている間は押せない）。覆うのは**ボタンの大きさだけ**（帯にしない。地もボタンの下だけで、ボタンの間は端末が押せる）。表示の面の見出し・帯・パネルの外（端末の領域の中）で、浮いた窓の層より下に置くので、窓の操作を邪魔しない。
- **操作**: 分割（右へ・下へ）と最大化は、今ある操作（`pane.split`・拡大表示〔zoom〕）をそのまま呼ぶ。最大化している間は、同じ場所のボタンが「元に戻す」になる（印と読み上げのラベルが替わる）。**閉じるは、押したら必ず確認する**（今の確認のダイアログ。エージェントが居ない素のシェルでも）。取りやめると何も閉じない。キー（`prefix+x`）と右クリックのメニューの「閉じる」は今のまま（素のシェルは確認なしで閉じる）。
- **入りきらないとき**: 名前は省略記号で切る。それでも入らないときは、分割の 2 つを先に隠す（最大化と閉じるは残す）。極端に狭い pane は、名前を出さない（ボタンに重なって押せなくなるため）。
- **キーボード**: ボタンは Tab の順に入れない（`tabindex="-1"`）。キーは、今のキー（分割・拡大表示・閉じる）と、pane の枠へ Tab → Enter で開くメニューで足りる。押したとき、フォーカスは端末に残る（`body` に落ちない）。押したときに、その pane が選ばれる。
- 名前の D&D（つかんで動かす）・右クリックのメニューには、混ざらない（ボタンの上からは D&D は始まらない）。モバイルの 1 列の画面と、狭い窓（1 列の配置になるとき）は、変えない（ボタンも、28px の名前の行も出ない）。
- **最大化している間**に［右へ分割］を押したときの結果は、キー（`prefix+v`）と同じ（どちらも同じ `pane.split` を送る。E2E で確かめている）。
- 数値は仮置き（見出し 0.95 倍・濃さ 0.9・名前の行 28px・ボタン 24px）。絵で見て破綻は無いが、使いながら調整する。

## tab バーの設定・tab と画面の切り替えのボタン・サイドバーのカード（PR6）

- **tab が 1 つのときも tab バーを出す**（設定「表示」の切り替え。共有の設定 `tabBarAlways`）。**既定は様式に従う**（クラシック: 出さない・モダン: 出す）。選んだ値は、様式を切り替えても残る。選んだ後は「既定に戻す」で、様式に従う状態へ戻せる。tab が 2 つ以上のときは、どちらの値でも出る。出る・消えるときの端末の桁・行の落ち着き（`client.view` が pane ごとに 2 回以内）は、モダンの配置（PR4）と同じ。端末版（`soda`）は、この項目を読まず、知らない項目として保つ。
- **tab と「基本画面／グラフ」の切り替えのボタンは、同じ言葉の見た目にそろえる**。
  - **モダン**: tab を、切り替えのボタンと同じ形（区切られた丸いボタンの並び）にする。数値は `uiStyle.css` の `--soda-shape-seg-*`（文字 0.8em・余白 0.2em 0.3em・すき間 2px・角 `radius-s`・線 1px・高さ `control-h`）を、**切り替えのボタンと tab が共有**する。tab の働き（名前の変更・閉じる・D&D・pane を落とす・右クリック・「＋」・あふれたとき・右端の帯）は変えない。
  - **クラシック**: 逆に、切り替えのボタンを tab の見た目にする（文字は継承・左右 1em の余白・地なし・右に区切りの線・選んでいるものは `--soda-menu-active-bg`・角なし・押さえた時の地の変化なし）。**クラシックで変わるのは、このボタンの矩形の中だけ**——帯の外形の高さは、これまでと同じに保つ（これまでと同じ大きさの見えない箱が高さを決め、ボタンはその高さいっぱいに伸びる）。たたんだ幅では、ボタンの大きさを今のまま、塗りだけを tab の言葉にする。
- **サイドバーの区画（spaces・agents）は、モダンではカード**（角の丸い面・薄い地〔`--soda-fg` を 5% 混ぜる〕と縁・面の間と端の余白 8px）。区画の高さのつまみ（境目）は、余白・すき間の分を引いて計算し、ポインタに付いてくる。たたんだサイドバーは、カードにしない（幅が無い）。右の主な領域（pane の並ぶところ）は、カードにしない（利用者の決定 2026-10-10）。数値は `--soda-shape-card-gap`・`-card-radius`・`-card-tint`。

## 対象外（モダンでも、クラシックのまま）

- 端末版（`soda`。画面の様式の設定を読まず、設定の画面にも出さない。保存された値は、知らない項目として保つ）。
- 端末の中身（xterm の描画・文字）。
- 表示の面（`sodactl display`）の枠の中（`DisplayFrame`・印「スクリプト」・`public/display-view/*`。モダンでは、外側の見出し・帯の行〔`DisplayPanelHead`・`PaneBands`・`DisplayTray`〕も、いまは変えない。高さが配置の計算に使われているため。PR3 以降で扱う）。
- モバイルの 1 列の画面の骨組み（`MobileShell`。pane の枠が無いので、すき間も無い）。
- `<ask-form>`（質問のフォームの部品。Shadow DOM）の中・`view`（成果物の表示）の中。外側のダイアログの縁（影・角）だけが変わる。
- 拡張の承認・確認のダイアログの**文言・ボタンの順・既定のフォーカス・待ち・コマンドの全文の表示**（変えるのは、余白・高さ・影だけ）。
- グラフの画面と、その中の部品（PR4）。
- 畳んだサイドバーの左右の余白（クラシックと同じ内側の幅のまま）。

## 開発者向け

- E2E をモダンで流す: `UI_STYLE_E2E=modern`（`packages/e2e/src/support/fixtures.ts`。localStorage の設定の読み出しに `uiStyle: "modern"` を足す）。ただし、クラシックの値（太さ 4・6・2px）を直に確かめる spec（`appearance-settings.spec.ts` の太さの項）は、モダンでは値が違って落ちる。
- 絵を撮る: `UI_STYLE_PR2_SHOTS_DIR=<dir>`（`ui-style-pr2-shots.spec.ts`。端末の文字を隠さない・偽のエージェントの画面つき。クラシックとモダンの細い・既定・太いを、暗い・明るいで）。比較用の画像は `ui-style-shots.spec.ts`（端末の文字を隠す）。
- モダンの配置の絵（クラシックとモダンを並べて見る）: `UI_STYLE_PR4_SHOTS_DIR=<dir>`（`ui-style-pr4-shots.spec.ts`。tab が 1 つ・tab が 複数・畳んだサイドバー・新規のメニュー・全体のメニュー・workspace の右クリック。暗い・明るい）。配置の E2E は `ui-style-layout.spec.ts`、pane の操作ボタンの E2E は `ui-style-pane-actions.spec.ts`（絵は同じ `ui-style-pr4-shots.spec.ts` の `actions-` の組）。
- 設計と決定: `.aidev/works/20261008-ui-style/`（`design.md` 追補 01・`decisions.md`）。
