# 会話の記録・要約・エージェント操作

ペインのヘッダーに「送信メッセージ」「会話の要約」と、対応するエージェントのよく使う操作を表示します。狭いペインでは「⋯」にまとめます。Webと端末版の設定「エージェント操作・要約」で表示するボタンを選べます。情報ボタンは先頭です。clearは既定で非表示です。

送信メッセージと会話の要約、過去セッションはClaude Code／CodexのJSONL記録に対応します。記録がない・対応していないエージェントのボタンは表示しません。ツールの実行結果・システムの環境説明は送信メッセージに含めません。

## 送信メッセージ

一覧を選ぶと会話ウィンドウの該当箇所へ移ります。端末に同じ本文が一意に残っていれば端末もスクロールします。画面の再描画や履歴の上限で本文が消えている、繰り返しがあり一意に決まらない、短い本文の場合は、JSONLの記録を窓で表示します。端末への入力・セッションの巻き戻しは行いません。

100件ずつ読み、「続きを読む」で次へ進みます。1ページの読取は1 MiB、長い本文は先頭8192文字までで、その場合は画面に一部表示と明記します。端末版は↑↓で選びSpace／クリックで会話を表示、Enterでペインの会話全体を要約、nで続き、Escで戻ります。

## 要約

設定でClaude CodeかCodexとモデルを選びます。要約用セッションは自動管理し、作業中の会話には送信しません。同時生成は2件、120秒で停止します。

要約は元の会話の種類とセッションIDごとに `stateDir/summaries/` に保存します。ウィンドウを開くと保存済みの要約をすぐ表示し、追加された会話があればその旨を表示します。「要約を更新」は前回の要約と追加された本文だけを渡し、変化がなければモデルを呼びません。「履歴から作り直す」は前回の要約を使わず再生成します。モデルの変更・記録の置換や短縮時も再生成します。再生成に失敗しても保存済みの要約は残ります。更新日時と省略の有無を表示します。

標準は手動更新です。設定「ターン終了後に要約を自動更新」を有効にすると、エージェントがworkingからidleへ移った際に更新します。モデルの利用量が発生するため、不要なら無効にしてください。要約は目的・決定事項・完了作業・残る課題を日本語でまとめます。各更新の読み取りは50ページ・50MiBまで、入力は10万文字までで、省略があれば明示します。端末版はEnter/rで更新、Spaceで保存済み要約を開き、Shift+Rで履歴から作り直します。

Web版の会話履歴・要約ウィンドウは右下のつまみで幅と高さを変更できます。ヘッダーで移動でき、狭い画面ではサイズを画面幅・高さに制限します。

Claudeは組込ツール・MCP・hooksを無効にします。CodexはサーバstateDirの独立した `summary-codex/` に認証とモデル／provider設定のみを写し、通常のMCP・hooks・plugins設定を継がず、read-only／承認never／Web検索無効で実行します。Codexの読取ツール自体は利用可能です。要約専用IDは `summary-sessions.json` に記録します。通常の作業ペインへの要約指示の入力は行いません。

## よく使う操作

Claudeはcompact・clear・usageと承認モード切替（Shift+Tab）、Codexはcompact・clear・statusとpermissions画面、GitHub Copilot CLIはcompact・clear・usage・permissionsへの導線を提供します。エージェントがidleの時だけ実行できます。CLIのモードを即座に変更するものと選択画面・説明を開くものがあり、承認操作は各CLIのUIで行います。

継続できる別ペインの質問は既存のforkを使います。独立したbtw機能は追加しません。forkは対応エージェントの会話を引き継いで別セッションを起動する機能です。

## 過去セッション

利用状況画面の「過去のセッション」で一覧を取得・検索し、「別ペインで再開」できます。端末版の利用状況はhで一覧を開きます。起動先にPJフォルダが設定されている場合は、そのフォルダが優先されます。

一覧はサーバ側のClaude／Codexの通常の保存場所からJSONLを探索します。CLIの `/resume` が使う索引・非表示設定・検索条件とは別のため、完全に同じ一覧になる保証はありません。上限内の最新300件の見出しを読み、最大100件を表示します。上限を超えた場合は一部の一覧と明記します。任意のファイルパスをクライアントから渡して読む方式ではありません。

## 通知の共有

端末版のアプリ内トースト・通知一覧とWebの通知一覧は、先送り／対応済みの状態をサーバ経由で共有します。トーストを閉じるのは先送り、通知一覧で削除または対象へ移るのは対応済みです。通知の表示・音・OS配送の設定は従来のものを使います。保存は最大512件・7日、対応済みを後着の先送りで戻しません。

コマンド対応は各CLIの公式仕様に従います。GitHub Copilot CLIは[公式コマンドリファレンス](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-command-reference)を参照しています。

Codex のモデル欄には、表示名ではなくモデルID（例: `gpt-6-luna`）を指定する。GPT 系の表示名を入力した場合は実行時に小文字に正規化する。独自プロバイダーのモデル名と Claude のモデル名はそのまま保持する。モデルを利用できない場合は、その旨をWeb/TUIの要約画面に表示する。CLIの生の診断は画面へ公開しない。

画像やツール出力などで1行が1MiBを超えるJSONL記録がある場合、その行を読み飛ばして続きを取得する。1行の走査は最大16MiB、要約は1回の更新につき50MiB以内・最大50回の読み取りに制限する。上限に達した場合も取得できた会話を使い、省略があることを画面に明示する。
