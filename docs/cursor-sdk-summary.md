# Cursor SDKで要約する（任意）

要約エージェントにCursorを選ぶ場合は、通常の`cursor-agent`とは別の公式`@cursor/sdk`ローカル実行経路を使います。SDKの「ローカル」はエージェント処理の実行場所であり、モデルの推論先はCursorのサービスです。

この経路には、サーバ実行環境の`CURSOR_API_KEY`、または同じ利用者が公式SDKの`Cursor.auth.login()`で事前に取得したSDK専用のログインが必要です。SDKの公開ログインAPIはブラウザでの本人操作によりAPIキーを発行します。操舵室はログインやブラウザ表示を自動実行しません。通常のCursor CLI・アプリにログイン済みでも、その認証は自動流用しません。SDKや対応する認証がなければ、利用できない理由を表示します。CLIやクラウドモードへ自動的に切り替えることはありません。

APIキーは操舵室を起動するサーバ環境へ設定してください。会話入力・モデル名・コマンド引数・画面の設定値へ書かないでください。保存済みSDKログインは公開APIから読むだけで、操舵室はログインファイルの保存・削除・書換えをしません。SDKログインの既定の場所は`~/.cursor/sdk/auth.json`です。期限切れや異なるバックエンド用のキーは利用しません。

毎回別のNodeワーカーで、空の仮想ファイルシステム、ツール許可なし、MCP・サブエージェント禁止、環境設定の参照なし、空の追加ツール、専用の一時保存先を指定します。元の会話へ送信・再開しません。通常のプロジェクト設定、ユーザー設定、フック、プラグインを要約処理へ持ち込みません。個別のeffort指定と要約セッションの再利用には対応していません。

要約は120秒、本文128KiB、処理中の出力全体512KiBまでです。接続・対象会話が変わった場合やサーバ停止時には、そのワーカーだけを停止し、終了後に一時保存先を削除します。禁止ツールのイベントが返っても結果を採用しません。モデルやSDKの生のエラーを通知へ載せません。

## 配布と確認範囲

任意依存`@cursor/sdk`は1.3.1に固定しています。導入時は配布先で`pnpm install --frozen-lockfile --ignore-scripts`を行い、SDKの分割された実行ファイルと対応プラットフォームの任意依存も配置してください。ビルド済みの操舵室ファイルだけをコピーしてSDKがない場合、この要約経路は利用できません。SDKを使わない他の機能は継続できます。Node24を使用します。

Linuxの隔離環境で、公式SDKによる空のツール許可とユーザー・プロジェクトフックの抑止を確認しています。アプリ側の成功応答・禁止ツール・期限・キャンセルは公開APIのテスト用差し替えで検証します。これはSDKサーバ自身による悪意ある応答の拒否や実モデルの成功を証明する検証ではありません。プラグインの実動作を伴う対照、WindowsでのSDK実行、実アカウントでの要約は別途の確認が必要です。

公式契約: [Cursor TypeScript SDK](https://cursor.com/docs/sdk/typescript)。
