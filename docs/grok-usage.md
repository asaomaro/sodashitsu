# Grok CLI の利用状況

現在の pane に確認済みの Grok 会話がある場合、その会話の `usage.json` からトークンと報告済みコストを読みます。CLI・モデル・バックグラウンドサービスは起動しません。会話が未確認、集計がまだ無い、記録が壊れている場合は未取得です。0件・0ドルとして補いません。

トークンは Grok のセッション累計です。キャッシュの読み書きを入力と分けて表示し、子の利用分を別に足しません。不完全な集計は「部分」として扱います。コストは記録の USD ticks（1 USD = 100億 ticks）だけを換算し、単価から推測しません。一部の呼び出しだけにコストがある場合もその旨を保持します。

この集計から、現在のコンテキスト使用率、現在のモデルや effort、承認設定、アカウントの上限は分かりません。集計の主要モデルを、現在のモデルとして表示することもありません。これらは取得できる別の正式な報告があるまで未取得です。

導入済み Grok CLI 1.0.77 が生成した形式の集計ファイルを読めることと、操舵室の通常の利用状況 API へ届くことを、隔離した生成データで確認しています。実際のモデル利用量や、CLIを自然に起動した直後の会話の取り付きを検証したという意味ではありません。

詳しい共通の表示・数え方は[エージェントの利用状況](agent-usage.md)、実装側の出典は [Grok Build の公開ソース](https://github.com/xai-org/grok-build)です。
