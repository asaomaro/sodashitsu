# 端末版の機能の扱い（AC15）

引数なしの `soda` で開く端末の中の画面（以下「端末版」。20260927-cli-mode）について、herdr と Web 版の全機能項目を
端末版でどう扱うかを分類したもの。調べた元は `.aidev/works/20260927-cli-mode/research-inventory.md`（herdr のソース・
`docs/herdr-parity.md`・`packages/web/src` の出典つき）で、この docs はそれを成果物として整え、**「対応」「読み替え」の行が
すべてどれかの受け入れ基準（AC）で検証されていること**を示す役割を持つ。

herdr と Web 版の対応は `docs/herdr-parity.md` を見る（ID の H01〜H52 はそちらと同じ番号）。

## 分類の凡例

- **対応** = herdr・Web 版と同じ機能を端末版でも持つ
- **読み替え** = 端末の流儀で同じ目的を満たす（どう読み替えたかを書く）
- **非対応** = 端末では原理的に出来ない・意味が無い（理由つき）
- **サーバ機能** = 画面に依らずサーバ・`sodactl` にあるもの。端末版はそのまま恩恵を受ける（「対応」の一種。検証は既存の work と AC19〔既存の挙動を変えない〕）
- **対象外** = Web 版でも後続に回したもの（`docs/herdr-parity.md` と同じ扱い）
- **検証した AC** = この work（`.aidev/works/20260927-cli-mode/requirements.md`）の AC の ID
- **(要確認)** = 04-tui-ops・05-tui-features の実装の後に、実際に作ったものと突き合わせて確定する行（下書きの時点の印。清書で消す）

## 区別できないキー・外側の端末との衝突

- 端末は一部のキーの組合せを区別して送らない（例: 多くの端末で `ctrl+shift+文字` は `ctrl+文字` と同じ列、`ESC ESC` と `ctrl+alt+[`）。
  端末版は Kitty keyboard protocol を使わない（pane のアプリへ同じ列を送れないため）ので、この組合せはキー設定に割り当てても届かない。
- 外側の端末が先に取るキー（コピー・貼り付け・タブの切替等）は端末版に届かない。既定の衝突と回避（prefix の変更・tmux の `send-prefix`）は `docs/tui.md` に書く。 (要確認)
