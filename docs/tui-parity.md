# 端末版の機能の扱い（AC15）

引数なしの `soda` で開く端末の中の画面（以下「端末版」。20260927-cli-mode）について、herdr と Web 版の全機能項目を
端末版でどう扱うかを分類したもの。調べた元は `.aidev/works/20260927-cli-mode/research-inventory.md`（herdr のソース・
`docs/herdr-parity.md`・`packages/web/src` の出典つき）で、この docs はそれを実際に作ったもの（`packages/tui`）に合わせて整え、
**「対応」「読み替え」の行がすべて受け入れ基準（AC）か試験で検証されていること**を示す役割を持つ（AC1〜AC14 に当たる基準が無い herdr の細目は、
「AC なし（試験: …）」と書いて単体の試験を根拠にする。decisions D20）。

herdr と Web 版の対応は `docs/herdr-parity.md` を見る。同じ ID は同じ項目（H17-18・H38-40・H45-46 はそちらの複数の行を 1 行にまとめた）。
そちらに無い ID（H04m・H04w・H08b・H10b・H19b・H19c・H22b・H26e・H26f・H27b・H29c〜H29e・H43b・H50〜H52）は、端末版の下調べで見つけた herdr の細目としてこの一覧で足したもの。使い方は `docs/tui.md`。

## 分類の凡例

- **対応** = herdr・Web 版と同じ機能を端末版でも持つ
- **読み替え** = 端末の流儀で同じ目的を満たす（どう読み替えたかを書く）
- **非対応** = 端末では原理的に出来ない・意味が無い（理由つき）
- **サーバ機能** = 画面に依らずサーバ・`sodactl` にあるもの。端末版はそのまま恩恵を受ける（「対応」の一種。検証は既存の work と AC19〔既存の挙動を変えない〕）
- **ブラウザだけの設定** = 共有の設定（decisions D3）の項目のうち、ブラウザの画面の見た目だけに効くもの。端末版の設定画面からも変えられ、
  「ブラウザの画面の設定です（端末版の画面には効きません…）」と注記を出す
- **端末版だけの機能** = herdr にも Web 版にも無く、端末の事情で端末版だけが持つもの（H29e）
- **端末版だけの設定** = 共有の設定の `tui` 節のうち、端末版の画面にだけ効く項目（設定画面に「端末版だけの設定です」と注記が出る）
- **対象外** = Web 版でも後続に回したもの（`docs/herdr-parity.md` と同じ扱い）
- **検証した AC** = この work（`.aidev/works/20260927-cli-mode/requirements.md`）の AC の ID

## 区別できないキー・外側の端末との衝突

- 端末は一部のキーの組合せを区別して送らない。例: 多くの端末で `ctrl+shift+文字` は `ctrl+文字` と同じ列、`ctrl+i` は `Tab`、`ctrl+m` は `Enter`。
  **`Esc` を素早く 2 回押すと `ctrl+alt+[`（＝`alt+Esc`）と同じ列**（`ESC ESC`）になり、端末版は `ctrl+alt+[` として読む（1 回ずつの `Esc` は 25ms 待って確定する）。
  端末版は Kitty keyboard protocol を使わない（pane のアプリへ同じ列を渡せないため）ので、これらの組合せはキー設定に割り当てても区別されない。
- 外側の端末が先に取るキー（コピー・貼り付け・タブの切替・全画面等）は端末版に届かない。既定の衝突と回避は `docs/tui.md`「外側の端末との衝突」。
