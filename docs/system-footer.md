# 画面下部のサーバー情報

設定 → 表示 →「画面下部のサーバー情報」で「フッターを表示」を入にする。初期状態は非表示で、CPU使用率とメモリ使用量が選択されている。設定画面は表示有無だけを扱い、表示内容はフッター左端の［⋮］から「フッターの設定」を開いて選ぶ。表示項目をすべて外しても設定ボタンは残る。表示有無・項目・グラフ設定はWeb版・端末版で共有する。

- CPU使用率: 前回の取得との差から求める全論理CPUの使用率。最初の取得ではまだ表示しない。
- メモリ使用量: 使用量／総量と割合。LinuxではMemAvailableを使い、解放できるキャッシュを使用量から除く。それ以外はOSの空きメモリを使う。
- Sodashitsuのメモリ: サーバープロセスのRSSとOS総メモリに対する割合。ペイン内のエージェントのメモリとは別。
- ロードアベレージ: 1／5／15分の値。Windowsでは取得できない。
- 稼働時間: サーバーが動くOS環境の起動からの経過時間。
- サーバー名: サーバーのホスト名。
- エージェント総数・状態別件数: 接続先サーバーの全ワークスペースのエージェントペインを集計する。作業中・待機・応答待ち・不明を個別に選べる。仮想ペイン、過去セッション、エージェント内部のサブエージェントは含まない。

CPU・メモリ・Sodashitsuのメモリは、statuslineと同じ斜線ブロック・四角・丸・ASCII・半段階ブロック（5個）のグラフパターンを個別に選べる。グラフを非表示にしても数値の割合は残る。既存設定ではグラフは非表示を維持する。半段階ブロックは`░`・`▒`・`█`の5記号で最も近い10%へ丸めて示す（50%は`██▒░░ 50%`）。数値はグラフの丸めとは別に表示する。

WSLで起動している場合はLinux環境の情報で、Windows全体のCPU・メモリではない。別マシンに切り替えた場合は接続先サーバーの情報になる。

Web版は画面最下部の1行、モバイル版は端末画面・予約画面の最下部、端末版は端末・グラフ・状況・予約画面の最下行に表示する。端末領域から必要な高さを確保する。Web版の長い情報は横方向にスクロールでき、端末版は幅に収まる分を表示する。

約2秒ごとに更新する。非表示・未接続・非表示のブラウザタブでは取得しない。エージェント件数は取得時の状態を集計する。サーバー側はOS情報の1秒分の結果を共有し、表示していない間に計測タイマーを動かさない。取得に失敗した場合は古い値を残さず知らせる。取得できない項目は省略し、選んだ項目をどれも表示できない場合は、その旨を表示する。

開発用の読み取りRPCは `server.resources`（引数 `{}`）。認証済みの接続からのみ呼び出せる。`pane.sock` には公開しない。
