# 切り出した範囲: D&D の表現とタブの並べ替え（次の作業の要件のもと）

`20261004-ui-interaction-polish` の要件から分けた。番号は元のまま。独立点検 24 件を反映した後の文面。

## 背景（利用者の指摘）

workspace・pane・タブの D&D は、操作できるのか、今ドラッグできているのかが分かりづらい。掴んだものの見た目が変わらず、ドラッグの像も無く、落とし先は行の枠だけで、どこに入るのかが分からない。タブは、ブラウザ版ではドラッグで並べ替えられない。「表現をモダンにしてください」。

## 機能要件

- F7: ドラッグできるもの（workspace の行・グループの見出し・pane の名前・タブ）は、マウスを乗せると掴めることが分かる: カーソルが「掴める」形（grab）になり、行・タブは hover の背景になる。
- F8: ドラッグが始まると（ポインタが 6px 動いたら。今の閾値のまま）、**掴んだものが元の場所で薄くなり**（不透明度 0.4 程度）、**ポインタに付いて動く像**が出る。像の中身: workspace は状態のアイコンと名前、グループの見出しは名前と件数、pane は名前、タブは名前。
- F9: workspace の行・グループ・タブの並べ替えでは、**入る位置に線**が 1 本出る（行と行の間・タブとタブの間）。グループの中へ入る位置では、線がグループの字下げの位置から始まり、そのグループの見出しが強調される。線は、落としたときに実際に入る位置と一致する。
- F10: pane のドラッグでは、今の表示（縁は分割・中央は入れ替え）を保ったうえで、落としたらどうなるかを像に言葉で出す。言葉は落とし先で決まる: pane の左右上下の縁＝「左に分割」「右に分割」「上に分割」「下に分割」／pane の中央＝「入れ替え」／タブ＝「このタブへ移す」／workspace の行＝「新しいタブへ移す」。
- F11: 落とせない所にいる間は、像に「落とせない」印（禁止の記号）が付いて薄くなり、線・面は出ない。そこで離すと、何も起きずに元へ戻る。落とせない所: workspace・グループ＝サイドバーの一覧の外と、動かしても順が変わらない位置／タブ＝そのタブバーの外（別の workspace へは運べない）と、順が変わらない位置／pane＝落とし先（pane・タブ・workspace の行）でない所と、自分自身・自分のいるタブ。`Esc` で取り消すと、像が消えて元へ戻る（今ある動き）。ダイアログが開いたときは、取り消しになる（今ある動き）。
- F12: 一覧の端（上下 24px。タブバーは左右）へドラッグしたままにすると、その一覧が自動でスクロールする。
- F13: ブラウザ版で、タブをドラッグして並べ替えられる（同じ workspace の中。結果はキーの `move_tab_previous/next` を繰り返したのと同じで、ほかの画面にも伝わる）。


## 受け入れ基準

- [ ] AC4: workspace の行をドラッグすると、元の行が薄くなり、ポインタに付いて動く像に、その workspace の状態のアイコンと名前が出る。グループの見出しを掴むと、像に名前と件数が出る。離すか `Esc` で、像が消えて行の見た目が戻る。
- [ ] AC5: workspace の行をドラッグ中、行と行の間に入る位置の線が 1 本だけ出て、離すと、その位置に入る（線の位置と結果が一致する）。グループの中に入る位置では、線が字下げの位置から始まり、そのグループの見出しが強調される。
- [ ] AC6: 落とせない所（workspace: 一覧の外・順が変わらない位置／タブ: タブバーの外／pane: 落とし先でない所・自分のいるタブ）では、線・面が出ず、像に禁止の印が付き、離しても何も変わらない。
- [ ] AC7: pane の名前をドラッグすると、元の名前が薄くなり、像に pane の名前と、落とし先に応じた言葉（F10 の一覧: 左／右／上／下に分割・入れ替え・このタブへ移す・新しいタブへ移す）が出る。
- [ ] AC8: ブラウザ版でタブをドラッグすると、元のタブが薄くなり、像にタブの名前が出て、タブとタブの間に線が出る。離すとその位置へ並べ替わり、読み込み直しても、ほかの画面でも、その順になっている。
- [ ] AC18: workspace の行・グループの見出し・pane の名前・タブにマウスを乗せると、カーソルが掴める形になる。
- [ ] AC19: workspace が一覧に収まらない数のとき、行を一覧の下の端へドラッグしたままにすると一覧がスクロールし、最初は見えていなかった位置へ落とせる。

## 共通（元の要件から）

- 動き（0.1〜0.2 秒）と、OS の「動きを減らす」での抑制（元の F24・AC14）。
- 色は既存のテーマの変数から。8 つのテーマでコントラスト 3:1（元の AC21）。
- ドラッグ中のポインタの移動による計算は、1 回の描画につき 1 回まで。
- 像・線の見た目の細部は、design で画面の見本を作って決める。
