# 要件

ユーザーが挙げたダッシュボード不足要素、メイン／サブ消費比率、bash・Skill・MCP等のツール利用率を実装する。現在の画面設計も見直し、よりグラフィカルにする。複数のデザイン案を操作可能なアーティファクトで提示する。

- 集計対象、欠損、読取上限、取得日付範囲を表示する。
- 前期間比較、種類／モデル／プロジェクト・ワークスペース／設定単位／役割／セッションで絞り込む。
- 数値のみを永続化し、ログの続きから集計できるようにする。
- メイン／サブの比率、日週月の消費構成、親子関係とセッション単独分析を表示する。
- ツール分類・個別名・MCPサーバーを識別できる名前、Skill名、呼出回数、結果取得、成功／失敗を表示する。直接記録と推定を区別する。
- キャッシュ率、応答あたりの取得トークン、利用制限の予測と任意の画面内通知を表示する。
- 接続済みPCを既存の認証経路で横断比較し、ログ複製を含む単純合計であることを示す。
- CSV／JSON出力、ローカル時刻を用意し、既存のコストと隔離実行のAIレポートを維持する。
- ターン開始・完了・中断・失敗は、記録されたイベントだけを数える。成果品質・タスク達成率を消費量から推定しない。

機能をデータ収集／集計と画面へ分け、各モジュールを独立点検する。Claude Code・Codexの確認済みログ形式が期間履歴とツール集計の対象。他の種類や取得できない内訳は未取得／未対応と明示し、0に置き換えない。
