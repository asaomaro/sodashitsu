# 要件

Muse Codeへの対応に加え、Antigravity CLI・GitHub Copilot CLIをデスクトップエージェント、監督エージェント、会話、利用状況分析などClaude Code/Codexと同等に扱う（2026-11-02の利用者追加指示）。既に実装中のMuse対応は引き継ぐ。完了後mainへpushする既存指示を継続する。

- 共通機能を種類ごとの分岐漏れなく利用できるようにする。
- CLIごとの公式仕様と導入済み実装を照合し、実在する記録・API・権限の範囲を守る。
- 未取得の数値やクレジットをUSDや0へ捏造しない。
- 有料モデルを必要以上に呼ばず、生成記録・fake CLI・公式ローカルモードで検証する。
- 既存の会話・設定・作業中の端末を維持する。

変更が数十ファイルになるため、機能単位の小さい実装とレビュー/コミットへ分割する。最終独立レビューは全体と修正差分にも掛ける。
