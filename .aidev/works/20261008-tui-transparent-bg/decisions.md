# 決定の記録: 端末版の背景の透過

## D1: 設定の保存場所 — 手元の状態（`tui-state.json` の `transparentBg`）
- 端末のエミュレータの透過は端末ごとの設定なので、`colorMode` と同じく手元の状態に置く。**共有の設定（サーバに保存・ブラウザ版と共有）には足さない**＝protocol・サーバの変更なし・ブラウザ版の設定の画面は変わらない（AC4）。
- 値は `true` のときだけ持つ（無ければ無効）。読み込みは `true` 以外を捨てる。

## D2: 実装の形
- `ThemeColors` の 3 つ目の引数 `transparent`（`key` にも出るので、変わると `TuiApp.onPrefsChange` が全体を描き直す）。
- `ground("--soda-bg" | "--soda-menu-bg")`（画面の地）・`paneGround`・`paneColor(0, _, true)` が、透過のとき `DEFAULT_COLOR` を返す。`ui()` は変えない（強調・重なる部品の色はそのまま）。
- 既定の背景のセルは、`sgrOf` が背景の部分を出さない（先頭の `CSI 0` が背景を既定へ戻す）。出力に literal の `49` は現れないが、端末にとっては SGR 49 と同じ。差分の描画（`Screen.frame`）は色の数の比較なので、`0` ⇄ RGB の両方向で前の色が残らない（毎回 `CSI 0` から組み立てる）。
- pane の中身を前の格子から写す手がかり（`lastPaint` の key）は `theme.name` のまま（変えない）。透過の切替・色の上書きの変化は、`TuiApp.onPrefsChange` が `theme.key` の変化で `invalidate` するので、写しは残らない。
- 重なる部品の中に pane の中身を描く所（独自コマンドのポップアップ）は、`ThemeColors.solid`（透過を外した同じ配色）を `paintPane` に渡して、透かさない。

## D3: 透かす所・透かさない所
| 場所 | 透過のとき | 根拠 |
| :- | :- | :- |
| pane のセルのうち背景が既定のもの | 透かす | AC2 |
| pane の中身が無いときの塗り・切り取りの余り | 透かす | pane の既定の背景と同じ扱い |
| 画面の地（空き・「端末が小さすぎます」・「workspace がありません」の下地） | 透かす（`--soda-bg`） | AC2 |
| pane の枠の地・スクロールバーの `┃` の地 | 透かす（`--soda-bg`） | `--soda-bg` で塗っている |
| tab バーの地・隠した tab バーの印の地 | 透かす（`--soda-bg`） | AC2・B3 |
| サイドバーの地（行の通常の地・罫線の地） | 透かす（`--soda-menu-bg`） | **B3 が優先**。AC2 は `--soda-bg` と書くが、実際のサイドバーは `--soda-menu-bg` で塗っている（下の D4） |
| 狭い幅の上辺（1 列表示のヘッダ）の地 | 透かす（`--soda-menu-bg`） | tab バーの代わりなので B3 と同じ |
| プログラムが指定した背景（ANSI 16・256・RGB） | 塗る | AC3 |
| サイドバーの選択行・navigate の行（`--soda-menu-active-bg`・`--soda-accent`） | 塗る | AC3 |
| tab バーの今の tab（`--soda-menu-active-bg`）・`+`・モードの印（`--soda-accent`） | 塗る | AC3 |
| pane の枠・見出しの色（前景） | 前景のまま | 背景だけが対象 |
| 独自コマンドのポップアップ（`CommandPopup`）の中身 | 塗る | B2。中身は `paintPane` で描くので、透過を外した配色（`theme.solid`）で描く。枠・見出しは元から塗る |
| メニュー・ダイアログ・設定の画面・トースト・overlay（`--soda-menu-bg` を `ui()` で使う所） | 塗る | B2・AC3 |

## D4: AC2 と B3 の食い違い
AC2 は「`--soda-bg` で塗っている所」にサイドバーを含めるが、サイドバーの地は `--soda-menu-bg`（メニュー・ダイアログと同じ変数）。AC3 の「`--soda-bg` 以外で塗る所は変えない」を字義どおりにするとサイドバーは透けない。
B3「サイドバー・tab バーの地は透かす」を目的として採り、サイドバーの**通常の地だけ**（`ground("--soda-menu-bg")`）を透かした。メニュー・ダイアログ（`overlay.ts` ほか）は `ui("--soda-menu-bg")` のままで透かさない。

## D5: 残る限界
- 反転（inverse）属性のセルで背景が既定のとき、端末が前景と端末の既定の背景を入れ替える。その背景は端末のエミュレータの色になり、テーマの色ではない（ほかの端末プログラムと同じ動き）。
- **選択の表示も反転**（`TuiApp` が選択の範囲のセルに `ATTR.inverse` を重ねる）。背景が既定のセルを選ぶと、塗りはテーマの前景色で出るが、文字の色は端末のエミュレータの背景の色になる（文字の色はテーマのまま、の限界と同じ種類）。
- 文字の色はテーマのまま（対象外）。
