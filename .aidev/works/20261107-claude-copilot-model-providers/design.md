# CLI model metadata adapters

Ownership: only agent/assistantModelProviders/claude.ts, copilot.ts and provider tests. Shared result types are the separate UI-owned 93ff677b contract (this branch's duplicate3659fb1e is not a release patch). Common dispatcher, cache refresh, protocol fields and UI belong to the UI implementation.

Claude: fixed executable resolved through existing windowsAgentExecutable on Windows (standard npm shim resolves to Node entry, no arbitrary .cmd shell). Owned process, temporary0700 HOME/config/XDG/appdata and cwd, ordinary environment authentication inherited, no credential file copy or manual token extraction. Explicit no-session-persistence, no setting sources, hooks disabled, MCP empty/strict, tools empty and Chrome disabled. Send only SDK control initialize; no prompt, resume, session/new or model request. Only matching successful response.models is consumed, raw account/errors are not returned. CLI metadata is not guaranteed account availability or server freshness. Efforts come only from explicit supportedEffortLevels with supportsEffort true. Unknown effort values are ignored; absent support remains empty. Empty/error/malformed/timeout catalog is unavailable.

Budgets:10sec, combinedstdout/stderr2MiB,512modelrows, bounded ID/label, duplicate IDs rejected. Owned process group killed on completion/deadline/error exit; Windows uses taskkill /T /F with kill fallback. Return after physical child close and remove temp HOME in finally. No production pane or existing daemon is attached.

Copilot: installed @github/copilot0.0.362 exports getAvailableModels(AuthInfo), but no public normal-auth resolver; private imports, credentials extraction and a new SDK dependency are excluded. ModelMetadata has only model/label, no effort capability. The eight SupportedModel/CLIhelp choices are reference-only, all efforts empty; message explicitly states account catalog/effort unavailable. No process or authentication action is performed by this fallback.

Primary contract: https://code.claude.com/docs/en/agent-sdk/typescript#modelinfo and Query.supportedModels()/SDKControlInitializeResponse. Installed Claude2.1.319 binary independently contains these fields. Copilot installed sdk/index.d.ts ModelMetadata/SupportedModel and CLI --help. Static references and installed CLI model metadata are distinct from a remote account catalog.
