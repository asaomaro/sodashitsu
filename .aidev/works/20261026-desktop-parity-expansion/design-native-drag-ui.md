# N7 native drag browser / local CLI

Build on N4 applied-pointer/release receipts, N5 B source/file lane and N6 local proof/owned host. No old-code compatibility layer is added.

`DesktopNativeTransfer` is explicit opt-in after the existing file grant. Managed discovery uses a separate direct connection to the page's Root (`location.origin`), never the selected B or injected selected-machine connection. `native_helper.touch` every30s verifies existing owner/viewer/origin and readiness without creating a process or renewing its15min bound. Manual `sodactl desktop native-helper --origin <canonical origin>` runs locally without login, machine forwarding or command/path options. Its only stdout is the loopback locator; it waits for owned Gateway cleanup on interrupt.

Controller admission: genuine modifier-free left mouse down on the displayed normal monitor, applied input sequence ACK, helper arm and4px movement. Original down still goes through normal input; movement is held pending source selection. Exact `native_activate` release receipt must succeed within the original750ms before RDP relinquish/pointer capture release/local start. Failure before activation replays the buffered last point as normal movement. Wrong receipts/late responses cannot start work. Handoff callbacks are rechecked after reentry.

Native requests retain their per-file UUID while each B chunk gets a fresh anti-replay UUID. File authority survives intentional input relinquish, but grant revoke, helper/source loss or explicit cancellation immediately aborts. Ordinary blur or pointerup during the native operation must not cancel target extraction. Cancellation keeps a retiring gesture until actual native process close is reported; no replacement gesture can bypass the retained slot. Grant revoke retains the prepared helper for a future explicit file grant. Closing/changing the file lane stops discovery/bridge/controller; late async results are drained/ignored.

UI taskcheck: pointer reviewer. RPC/CLI/touch taskcheck: transfer reviewer. Independent whole review covers source delta including browser tests and docs; corrections receive a delta review. Generated browser memory target is not actual Explorer/OLE. Actual Explorer/Windows browser drop/cancel remains a field check. User confirms no Linux/macOS desktop devices; WSL does not establish native Linux/macOS screen/input parity.
