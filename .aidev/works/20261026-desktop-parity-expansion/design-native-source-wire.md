# Native B selection and approved file lane

Native Explorer drag remains incomplete until the browser-PC helper and browser controller are connected. This phase exposes B selection/offer/activation/read/heartbeat/abort through the existing authenticated file lane, without exposing B source paths in a native request or offer. Old-version combinations are outside the user-authorized scope.

The existing explicit file grant and canonical locally approved root remain mandatory. A fresh successful applied LMB-down private witness binds the exact control epoch, physical coordinate, root window and PID. Normal shares derive the native origin from the admitted relay URL. Sealed endpoint shares carry the original admitted outer relay origin through EndpointService → private Backplane root → registered Provider endpoint scope; private loopback origin is separate. Public native_prepare.origin must match this trusted origin and never establishes it.

The fixed disposable STA selection worker verifies the held button/current physical cursor/foreground window/PID and the existing normal-desktop, current-user, non-elevated Explorer/UIA adapter. It reads the selected item and selection twice; no clipboard or input injection occurs. SendInput success alone is insufficient to prove Explorer processed selection. Desktop icons, ambiguous tabs, UNC/device paths and unavailable UIA fall back to ordinary file transfer. Physical cursor checks use GetPhysicalCursorPos, matching the physical witness even under DPI scaling ([Microsoft API contract](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getphysicalcursorpos)). Real DPI/Explorer behavior is unverified here.

The parent uses only fixed bundled builder sources, fixed framework compiler/references/options and trusted launch SystemRoot. WSL uses fixed /mnt/c/Windows/.../powershell.exe and /usr/bin/wslpath; other Windows installation roots are not automatically discovered. Compilation starts after the private normal-helper proof and file negotiation, before a gesture. A new private directory has explicit current-user owner/protected user-only ACL. The retained compiler process has a20s timeout, exact owned kill/exit wait; parent compilation timeout30s. Capture is admitted for the remaining original750ms window, not a renewed750ms. The worker has an independent6s blocked stdin/UIA/output watchdog. Parent timeout/abort never substitutes for child close+exit0, nonce/epoch/window/PID match, strict UTF8/JSON and final monotonic deadline checks. Metadata output is bounded4MiB privately. Runtime shutdown aborts and waits capture, then removes only retained-identity generated binary and empty directory, without recursive deletion; abrupt OS/process crashes may leave private temporary build artifacts.

A B server process admits one native source snapshot at a time, at most100MiB/1000 entries (N2 limits). The budget is retained until an aborted preparation and its lease have drained; separate Node server processes have independent budgets. The browser-PC native worker has its own cross-instance/current-user slot. The fixed immutable snapshot is SHA verified before the manifest; directory records normalize to empty-content SHA and zero bytes. Existing100000-byte file-lane limits remain; offers above98000 bytes fall back intact rather than omit entries. The grant owns the source after intentional control release. Activation requires the exact physical-source, cleanup-request and original epoch receipt, within the original gesture deadline; ordinary input/render/send ACK is insufficient. Shared capture ownership is relinquished as well.

Cancellation is synchronous before the file queue and sticky even before preparation state exists. Gesture replay/tombstones are bounded4096; overflow disables this native epoch rather than evict a live tombstone. Revocation, session/config/source changes, pointer changes before activation, clock regression, stale gesture, cleanup error, source hash/path changes, idle5s and absolute15min invalidate the lease. A separate cancellation slot and5s native browser request timeout prevent ordinary30s file deadlines from extending native waits. No native local destination path or success is invented; actual OLE COPY completion still belongs to the pending helper/controller integration.
