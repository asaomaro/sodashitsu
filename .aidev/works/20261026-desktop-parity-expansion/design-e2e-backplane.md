# 10D1: private provider permission backplane

Scope: endpoint-owner process library, not mounted by composeServer or exposed as RPC. Public desktop behavior remains unchanged by default. The generated browser test joins Provider/backplane to10C Wire; it is not the product viewer. Required-encryption persistence, pairing UI, public opaque relay and actual child encrypted connections remain subsequent integration work.

One B process owns an HTTP listener bound only to127.0.0.1 on a random port; ordinary HTTP returns404. Header/request deadlines are5s, max64TCP connections; existing desktop relay admission/lane/helper limits apply. Each of at most8 roots owns a256bit random cookie, private session/machine UUID, one parent and at most8physical sockets, a single internal RPC channel and the local permission scope. The root API never returns its cookie/private origin/route IDs. Viewer upgrades require both exact Origin+Host/loopback and cookie. Provider lanes retain existing one-use role/session/origin tickets. Public target UUID is checked exactly once before translating to a private route; a cross-root child ticket cannot attach or consume the legitimate invite.

The internal LinkChannel adapter accepts only client.hello, desktop.capabilities and desktop.start. It parses bounded strict envelopes and serializes one request at a time; no settings/filesystem path/exec/general machine RPC is available. Provider start still uses all existing locally selected helper/input/display/audio/mic/file ceilings. A registered WeakSet scope can add only its exact ws://127.0.0.1:port origin. A forged scope, remote URL, different port or an old source epoch is rejected. Legacy start is refused when requireEndpoint(true) is enabled by the owner. This switch is in-memory only in this phase and is NOT yet a restart-proof downgrade policy.

Provider configure/dispose increments source epoch. Scope close invokes clientGone for owned helper starts/native sessions before root socket teardown, so direct UDP/native ownership is stopped too. The future owner service must call root.close synchronously from store revocation and handoff; the250ms poll is only a safety net. Async results, source callbacks and input/write/send/clipboard/files/mic authorization paths recheck scope validity. A rollback cannot revive an old root; fresh authentication is required. Local allowInput=false wins even if the helper advertises true. Raw Ctrl+Space stays ControlLeft/Space down/up, without IME rewriting.

Close invalidates routes/cookie first, isolates callback exceptions and completes channel/socket/HTTP cleanup. Repeated plane.close shares the same promise. Another shared root retains its own socket, ACKs/input permissions and common helper when one root stops.

Tests use only generated synthetic-helper processes, temporary files/private sockets, fake key events and generated PNG canvas paint. No OS capture, keyboard injection, clipboard, microphone/speaker or privileged driver/service installation occurs. Single owner/persistent protected require flag, authenticated child binding, endpoint pin UI/identity, public relay and agent recipient integration are still mandatory before claiming all-lane E2E.
