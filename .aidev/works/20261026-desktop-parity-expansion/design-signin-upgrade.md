# Explicit stopped-service package upgrade

No real service/config/installed files are changed during development or CI. This is an explicit elevated local operator command with owner SID, exact old reviewed raw manifest SHA, reviewed new source folder and exact new SHA. Actual primary administrator/actual user/owner mutex and finite five-minute authority are required. Never start/stop/kill, register/delete service, repair ACLs, replace barrier or delete/reset/recreate identity/trust/enrollment/runtime.

Require fixed existing service complete Manual policy, STOPPED (exit0 or1077/specific0; PID ignored), old fixed package retained and exact old SHA, no install.transition, empty admin and private pinned fixed parents/slot/runtime/admin. Hold immutable same barrier exclusive. The old RunJournal must validate initial or complete (independently observed exit0+Job0) with exact old package/barrier. A raw SCM stopped flag or empty/missing journal is never clean evidence. Keep this proof through source staging.

Copy verified new source into a new fixed-parent private UUID stage while old code stays pinned. Reject same manifest, preexisting stage/archive, source changes or revoked authority. Verify all stage file ACLs/hash/inventory and directory identity. Then recheck complete manual/stopped + old clean proof, change only start type to Disabled and inspect exact disabled/stopped policy. Disabled precedes durable transition marker, so old controllers and SCM do not start during partial maintenance. Marker is private, closed and purpose-bound, recording owner/UUID/old+new hashes/barrier/old clean state, exact runId and initial/observed-stop canonical digest/captured code+run+stage directory IDs and exact stage/archive names plus the fresh new runId. Unknown marker is never adopted.

Keep private parent identity and exclusive barrier held. Close only old code lease, old runs reader/file/root pins and stage lease/directory pins necessary for Windows rename, under Disabled+marker. Nonreplace rename old code to a private fixed-parent archive and stage to fixed code; reopen and verify exact same root identities, closed inventory, hashes and ACLs. Nonreplace archive old runs directory with captured identity, revalidate its initial/complete journal with old package/barrier, create new private runs and initialize a new package-bound initial record under this verified clean generation boundary. Preserve every other data file, runtime and old archives, without deleting anything.

Final proof retains old archive, old archived journal, new fixed package, same barrier and marker identity. Only after all checks remove this operation's exact known marker, restore Manual and inspect exact manual/stopped policy. No automatic start. After Disable, failure leaves existing archives/stage/marker/Disabled state (staging failures before Disable preserve Manual); no rollback deleting unknown data. Partial upgrade recovery remains a separate command/design until verified, never handled by rerunning initial installer/upgrade. Tests use ordinary generated folders, DPAPI/barrier, fake SCM and explicit test factories. Native public mutation remains untested.

The user does not require old-version compatibility or migration branches. Upgrade targets only the current fixed package and lifecycle schema. Old archives preserve data/evidence for explicit recovery, not execution compatibility.
