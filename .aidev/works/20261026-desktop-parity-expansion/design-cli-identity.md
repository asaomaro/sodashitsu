No network/login/Root grant, machine forwarding, peer trust, desktop capture or input. Output contains only initialized, role:agent and public fingerprint when initialized. Explicit initialization prepares missing owner directories then initializes the existing protected Node Store. Default is ~/.sodactl/desktop-agent. No implicit initialization on status; absent directory returns initialized:false after read-only ancestor validation.

Existing owner lifecycle unchanged; this CLI does not issue live permits or modify trust/policy.
