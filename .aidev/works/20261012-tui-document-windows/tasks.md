# 端末版の文書とフォームのウィンドウ

既存のdisplay契約を利用し、端末版のペインメニュー「表示ウィンドウ…」からtext/markdown/htmlを開く。floatの新規表示は対象ペインに焦点があり、別の窓を開いていない場合に開く。帯・通常のパネルも一覧から窓として確認できる。HTMLは静的な入力欄・select・checkbox・radio・buttonの限定的なフォームとして解釈し、display.actionに返す。作者のJavaScriptや外部接続は動かさない。

- [x] ウィンドウの右下ドラッグ／Alt+矢印によるリサイズ、上辺ドラッグ／Alt+Shift+矢印による移動。画面サイズ変更時の範囲補正。
