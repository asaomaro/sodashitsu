# 独立レビュー

review_summary_cache が display購読・世代と版の照合・静的HTMLフォーム・操作送信を点検。走査上限で入力欄を省略したときの不完全な送信、form属性による関連付け、非submitボタンの誤送信、フォーカス欄への毎描画スクロールを指摘。

表示上限／form属性がある場合に送信を無効化し、reset/input buttonは直接のdata-soda-actionがなければ送信しない。フォーカスを変更した場合だけ欄の位置へ移り、切断時には古い本文と取得版を破棄。再レビューで追加の重大指摘なし。

review_history_usage が座標・範囲補正・履歴/利用量連携・MarkdownとMermaidを点検。引用の記号を付けた後に行末が欠ける問題と、無方向接続を有向矢印にしてしまう問題を指摘。引用の本文幅を先に確保し、未対応の無方向接続は原文fallback。深い引用の奇数幅では日本語に最低2セルを確保する追加修正を行い、幅11/12で全文保持を確認。全ての修正を再レビューし、追加指摘なし。

送信成功後に窓を閉じる追補: review_summary_cacheが開始時と終了時のcontext一致・失敗時の入力保持を確認。再接続の台帳取得前に削除と誤認して閉じる競合を指摘。DisplayModel.readyを台帳同期完了後だけtrueにし、自動closeを同期後に限定。遅延subscribeの検証を追加し再レビューで指摘なし。
