# 最大化状態と表示の同期

依頼: 最大化した窓を移動しても最大化扱いが残り、リサイズできない。最大化と元のサイズへ戻すアイコンも同じ。

- 手動最大化の復元Rectとは別に、実際に適用した最大化boundsを保持する。内部のsetBoundsには再入ガードを設け、自分の最大化処理では解除しない。
- settings/tools/panelのmove/resizeで実boundsとの差を検出。移動で最大化位置を離れたら状態を解除し、元の大きさをpointer下・現在のworkArea内へ戻す。外部のサイズ変更も通常状態として扱い、リサイズ開始前にも同期する。
- 自窓限定window-stateの読取と、ローカルrendererだけへの状態変更イベントを追加。revisionで古い初回読取/イベントを捨てる。
- ボタンはホストの状態からSVGの単一矩形／重なった矩形、titleとaria-labelの「最大化」／「元のサイズに戻す」を切り替える。ローカルshellだけが対象で、remote WebContentsには引き続きpreload無し。

独立レビュー: review_bubble_resizeが、内部サイズ変更の再入除外、move後の通常サイズ・状態・リサイズ再開、アイコンと読み上げ名の同期を点検。必須指摘なし。
