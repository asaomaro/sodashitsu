# 端末版の起動アスキーアート

公式アイコンの舵輪と >_ を金色・青緑のASCIIで描く。初回接続前に同期描画し、接続後消去。起動待ち時間は加えない。再接続時は繰り返さない。小端末では短縮しGrid境界内に収める。描画は通常のScreenを通すためtruecolor/256色設定を共用。非TTYの既存動作は維持。接続待ち中のダイアログ・通知は起動画面の上から描画。

検証: 色セル/2カラー方式/小端末/接続後消去/待機中ダイアログ。独立レビューでダイアログを隠す問題を指摘され、decorateへ移動し回帰テストを追加。再レビューで必須指摘なし。ダイアログの修正を外してテストが落ちることを確認し、元のバイト列へ復元。生ログは negative-overlay.txt。

最終検証: pnpm build / pnpm typecheck 通過。TUI全84ファイル775件通過。
