# 端末版の起動アスキーアート

公式アイコンの舵輪と >_ を金色・青緑のASCIIで描く。初回接続前に同期描画し、接続後消去。起動待ち時間は加えない。再接続時は繰り返さない。小端末では短縮しGrid境界内に収める。描画は通常のScreenを通すためtruecolor/256色設定を共用。非TTYの既存動作は維持。接続待ち中のダイアログ・通知は起動画面の上から描画。

検証: 色セル/2カラー方式/小端末/接続後消去/待機中ダイアログ。独立レビューでダイアログを隠す問題を指摘され、decorateへ移動し回帰テストを追加。再レビューで必須指摘なし。ダイアログの修正を外してテストが落ちることを確認し、元のバイト列へ復元。生ログは negative-overlay.txt。

最終検証: pnpm build / pnpm typecheck 通過。TUI全84ファイル775件通過。

背景色ブロック版へ更新（追加要望）: 舵輪は公式SVGの輪・スポーク・8分割の色分けを空白セルの背景色で表す。中央 >_ だけ文字のまま。端末セルの縦横比を考慮し40×20/32×16/24×12に縮小し、小端末は短縮表示。偶数行の境界でも横スポークが欠けないよう補完。関連テスト6件、TUIビルド通過。実Gridからプレビュー画像を生成して視覚確認。review_bubble_resizeの独立レビューと微修正再レビューで必須指摘なし。

縦長の補正（追加要望）: 固定2:1を廃止しCSI16tで取得する既存cellSizeイベントの実寸を起動描画へ渡す。実寸未取得時は2.2。必要な行数でサイズを選び、1〜4以外の比率は既定に戻す。実セル11×24で補正画像を生成し視覚確認。異なる4つのセル寸法で描画のピクセル外接矩形の縦横比を点検。固定2:1に戻すとテストが失敗（negative-aspect.txt）、修正ソースをバイト一致で復元。review_bubble_resizeの独立レビューで必須指摘なし。

今回の最終検証: TUIビルド・型チェック、全84ファイル776件通過。
