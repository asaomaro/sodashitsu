# 操舵室アシスタントの配色テーマ

## 実装

操舵室画面のテーマに通常版（生成り色/紺文字/金色）とダーク版（アシスタントの紺色/金色）を追加。名前はsodashitsu-assistant / sodashitsu-assistant-dark。既存の明暗分類、設定、保存、起動時の控え、端末の配色、OSC色問い合わせを共通のテーマ経路で扱う。明暗ペアに追加してOS自動切替にも対応。既定テーマは維持。

## 点検・検証

- /root/review_bubble_resize が差分全体を独立レビューし、必須指摘なし。
- 318テスト通過（protocol theme、web theme controller/boot/UIトークン/コントラスト/端末、TUI theme）。既存の全テーマに対するチェックに新2種も含む。
- 実画面のテーマ選択・端末色・枠のコントラスト・OS追従・保存/再読込を既存theme-settings E2Eで検証する。

- 追加のテーマ通信・設定ダイアログ検証8件通過。全体ビルド・型チェック通過。
- 固定されたテーマ総数19、明暗の内訳11/8へ既存テストを更新。
- 隔離サーバのブラウザE2Eはテーマ操作に入る前の初期端末待ちで停止（2回）。Cookieを再利用する診断でも同じ箇所で停止したため、既存のログインヘルパーは変更せず元に戻した。配色のE2E成功とは扱わない。生の出力はtest-result.md。

## 稼働反映・実画面確認

実装e326c4ecをmainへpush。サーバhandoffで稼働8 PTYを停止せず引き継ぎ、保存した10 pane UUIDが全件残ることを確認。アシスタントphase=running / stage=ready。

稼働Webへ独立した認証済みブラウザで接続し、設定ダイアログに両テーマの選択肢があることを確認。保存設定を変更せず、DOMへ各テーマの実際のUIトークンを当てて通常/ダークのスクリーンショットを目視した。これは配色の描画・選択肢の確認であり、保存/OS連動/端末配色を含めた統合E2Eの代用とはしない。通常/ダーク画像は /tmp/sodashitsu-assistant-live.png と /tmp/sodashitsu-assistant-dark-live.png。
