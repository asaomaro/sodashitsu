# コード交換による操作委譲

操作されるPCからWSS `/machine-pairing` へ申請。操作する側の認証済みWeb/TUI通知・RPCだけに8桁コードを表示し、操作される側が別途伝えられたコードを送る。5分・誤入力5回・一回限り。申請ごとのWSへ紐付け、権限付与前の経路をBridgeEndpointへ接続しない。成立後だけ既存のDelegationGrantsで資格情報を発行し、操作される側で保存・外向き接続する。通常のログイン用トークンは共有しない。

上限: 無認証WS 16、最初のフレーム待ち10秒、フレーム1KiB、接続元ごと5分10回、接続元の記録256、申請元側8接続。申請名を機械名の既存規則で検証。TLS必須（ループバック以外）、Originを持つブラウザから直接申請不可、リダイレクトしない。未成立の申請はメモリのみで再起動時失効。

CLI: request/requests/confirm/reject-request。既存のSSH・JSON招待経路は保持。Web/TUIはsticky通知を表示し、成立・切断・期限切れで削除。別マシンを見ている間はローカルの軽い接続からも通知を受ける。画面接続前の申請はrequestsで確認可能。

サーバー保存・認証・試行制限を独立レビューする。実サーバー2台・ブラウザDOM・TUI画面で検証。稼働サーバーのhandoffは行わない。
