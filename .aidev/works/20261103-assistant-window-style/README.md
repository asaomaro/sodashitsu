# 設定・ツール画面の様式統一

利用者の依頼: 会話ウィンドウと同じデザインへ揃え、尻尾は付けない。

- 会話と共有する紺色の地、金色の枠、丸角、余白を使う。
- 固定ヘッダーと本文の内部スクロールを追加。スクロールバーの色も共有する。本文・既存フォーム・ツール処理は維持する。
- OS標準のタイトルバー/メニューを外し、ドラッグ領域と最小化・最大化/復元・閉じるをヘッダーへ配置。既存のネイティブリサイズを維持する。最小寸法360×360。
- 初回空画面の退行を避け、settings/toolsは引き続きopaque・show:trueで読み込み、ロード後に既存presentWindowで前面化する。
- window-actionのIPCはsettings/toolsの現在のmain frameだけ許可する。入力は3操作のenum。対象は送信した窓に固定し、任意の他窓を指定する機能は出さない。

独立レビュー: review_bubble_resizeが設定復元ではなく今回のnative frame/menu変更、送信元・役割・自窓への限定、first-show維持、内部スクロール、尻尾なしを点検。必須指摘なし。
