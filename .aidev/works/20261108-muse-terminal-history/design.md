# Muse terminal producer

Base d3e2aeee. Muse only. Existing strict authenticated history RPCs/collector/UI reused; no current fallback or active count addition. Codex/Copilot/AGY/Grok/Claude lifecycle semantics are unchanged.

A durable schema1/event parent stream owns a child only through exact nested_session_v1 child_session_bound + start_attested. Known payload versions are pinned to observed formal schema (spawn4, resume/bound/start/status/attempt1, runtime/result2). A literal result_ready is terminal; closing/closed/resultReady status alone does not create a terminal fact. Start/binding metadata are private and bounded256. A new spawn/resume/attempt/binding or unknown lifecycle/schema revokes the old fact; replacement binding requires new start. Initial first binding may pair an already attested start. No timestamp/model/name inference.

Native incremental parent scan keeps 4MiB/512MiB, line256KiB, dedup20k, and adds a Muse EOF seal to the same file/namespace generation. No additional body scan per RPC. Complete offset==size/newline is mandatory for history. Parent FD/path bigint revision is rechecked before/after, same-size rewrite resets namespace/fold; normal unrelated append can revalidate an unchanged formal fact. Four shared physical parent verification slots stay occupied through FD close; allowed/current/source checked afterward. Existing Muse current binding and observation resume behavior stay unchanged.

Native service proof captures same pane/instance/kind/ref/fresh/cwd. Child record path derives only from exact parent namespace and formal bound session; openMuseChildRecord verifies containment/regular/nofollow/owner/child stream and FD/path revisions. Public body is only existing workflow_child_result_submitted; no private thoughts/assistant_message_committed fallback. Terminal rows omit model/effort. Collector entry ID remains stable on identical formal proof/relist and is retired on changed attempt/source/namespace.

Muse recorded_at is an integer in microseconds. Public history timestamps use floor(ms), but a private usageStartedAt preserves formal birth precision for numeric filtering. The generic history numeric resolver accepts this optional provider birth (existing providers still use public startedAt). Accumulator uses raw Muse recorded_at only for birth comparison, preserving existing millisecond observedAt/source/self/token semantics. Same-millisecond -1μs inherited data is excluded while +1μs own usage is included. No parent total/USD/credits/derived total is synthesized.

Validation: generated records only, standalone service + fake CLI real compose/authWS. No actual model, authentication/login action, user-record read, user pane or Windows. Related Codex regression suite remains in checks. State/security change requires separate-context final review and byte-exact negative restoration; no duplicate global suite.
