# モバイルレイアウトと実PTYサイズ

モバイル表示では画面相当のcols/rowsを既定でサーバへ適用する。client.viewの直後・pane.subscribe前にclient.fitを送り、既存接続でデスクトップ表示からモバイル表示へ切り替わった場合も同じ順序で適用する。複数クライアントは従来のサイズ権限を保ち、別クライアントが大きさを決めたときは画面からはみ出さない縮小を行う。縮小だけを選ぶボタンは維持する。

- [x] モバイルの初期fitと既存接続の初回view後の通知、切断／再接続を検証。（独立レビュー対象）
- [x] 共有サイズへの追従、狭い上部バー、縦横回転・追加キー・隠れたpaneをブラウザで検証。
- [x] 対応するunit/E2E、negative control、build/typecheckと最後の独立レビュー・記録。
