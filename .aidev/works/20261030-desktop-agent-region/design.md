# Source-proven regional observations

An optional observe.region (transferred-image pixel coordinates, area <=1,048,576) narrows change verification and input to pointer actions inside the rectangle. The response still returns the entire image, explicitly marks regional pointer-only verification. Keyboard/text/wheel require full-image observation. No implicit fallback when a source lacks capability.

Windows computes SHA256 over nonce/geometry/BGR pixel rows before transmission, including unchanged/delta frame reports. Nonce binds each grant/configuration; revoke clears it. Regional action compares latest source evidence, freshness and geometry; default action still hashes the full transferred image. The existing human grant, owner binding, 120s deadline, one-use observation and final queued-input authority checks remain.

Shared capture allocates a physical UUID per member request, merges at most eight bounded regions, strips others' evidence, remaps only the owner proof. Configuration changes coalesce for at most100ms and detach sends removal. Root clear is ID-conditional and cancels matching in-flight snapshot. Protected lock screens remain human-only. Native Linux/macOS must not advertise unimplemented source proof.

Generated tests use owned Node helper processes, ephemeral loopback sockets, memory frames/pointers, and pure C# BGR arrays. Hardware latency/performance and real OS validation remain explicitly unclaimed.
