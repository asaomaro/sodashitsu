# 設計

新しいtools LocalRole/ローカルHTMLを追加。通常の枠付き・可変サイズの1窓を再利用し、会話ボタンから開く。会話HTMLから標準ツールと各ツールJSを除去。ツール窓は専用権限の固定IPCのみ利用し、会話送信・通知元返答・設定保存は許可しない。既存bubbleのツールAPI権限は互換維持するが、実UIはtoolsへ移す。

文面はdraft-messageでmainへ渡し、会話入力欄へ反映後にrevision付きACKで消費する。ACK前に新しい文面が来ても消さず、無効化/接続先変更ではpending文面を破棄する。自動送信しない。メディアは実際のownerへ許可し、その窓のhide/close/navigationで中止。会話だけを閉じても表示中のtools録音を中止しない。休止時はメディア所有窓だけを破棄し、他の窓は隠す。

予約編集はtoolsだが、届いたリマインダーの本文/確認ボタンは会話にも残す。
