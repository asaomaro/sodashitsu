# D1 standard tools / local file transcription verification

Generated memory adapters and temporary files only. main integration mocks Electron clipboard/dialog and native RPC before importing main. Speech tests replace SpeechSynthesis and utterances with generated adapters. Two inference tests use ephemeral localhost HTTP fixtures and three generated bytes; they test real Node multipart/redirect behavior but never run Whisper or decode actual audio. No production Soda, real agent/model, actual microphone/screen/clipboard/speaker, GUI or OS setting was used.

Positive focused run:57 files /576 tests passed (native + complete protocol). Core scenarios include local notes concurrent persistence/corruption, explicit clipboard role boundary, no automatic model send, local-only voice, selected-file bounds, nonregular refusal, identity/change checks, cancellation retirement, budget/response bounds, real generated multipart/no Cookie/neutral filename and redirect refusal. Generated browser verdicts observe DOM/form state and browser bridge calls rather than an unrelated test client (e2e-observe-browser convention).

## Negative controls

15 temporary source/assets ablations failed the corresponding runtime assertions. Raw log content below preserves the runner output with only Markdown line-end whitespace removed; the original logs remain at the listed /tmp paths. Every source was restored byte-for-byte in finally; no compiled output was produced from mutated source. Vitest reads source; generated UI reads assets directly. The protocol origin control imports the protocol source directly.

The first audio-bound negative caused the test runner to exhaust memory while formatting a resolved25MiB buffer. That is not a valid negative result. It was interrupted and the source restored; the test now maps a fulfilled read to a short sentinel string before the rejection assertion, so failure output is bounded. The rerun below fails the intended assertion. The initial OOM log remains `/tmp/soda-assistant-tools-negative-audio-bound-initial-oom.log`. The retiring-read test always releases its deferred operation in finally, including assertion failure.
