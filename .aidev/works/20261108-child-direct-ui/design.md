# 子会話の正式入力能力への接続

子選択から開く既存専用会話窓を維持する。`agent.subagent_control` が direct と有効な UUID lease を返した対象だけ子用の入力欄を出す。未接続・旧サーバ・欠測では親への下書きを明示的に準備し、親への送信は従来の `agent.prompt_checked` のみ。プロバイダ製品自身の対応有無と操舵室の接続経路の対応を混同しない。

バックグラウンドの読取と送信時の fresh lease 読取は FIFO 直列化。文字入力中の10秒期限では入力内容を捨てず、送信を明示した時に新たな lease を取る。直前直後に親 instance/kind/ref/session・machine/client/接続・画面世代・入力内容を照合する。送信の二重起動を防ぐ。UUIDは Web Crypto のみを使い、HTTP origin で randomUUID が無い場合も getRandomValues から v4 を作る。暗号学的乱数を使えなければ送信前の準備失敗として止める。

accepted は受付であり作業完了ではない。send を試みた後の配送不明/例外/不正応答は同一対象の latch とし、自動再送しない。待機中に下書きだけが差し替わっても latch は保持し、新しい下書きは消さない。古い accepted は新しい下書きに適用しない。control の取得失敗は入力未試行として区別する。

Web は既存会話窓の移動・リサイズ・フォーカス・狭幅・Escを維持。新しい親窓内だけ読み取り部品を bare 表示にして重複見出し/閉じる/閲覧専用説明を省く。グラフなど単体の記録窓は引き続き閲覧専用。TUI は C で子入力、P で親下書き、Enterで送信欄へ移動後さらにEnterで送信、Escで履歴へ戻る。過長ペーストを黙って切り詰めず拒否し直前の入力を保つ。

情報パネルへ履歴を戻さない。終了子履歴入口と子利用状況は別の後続単位として未完のまま保持する。実daemon/実モデル/通常利用者セッション/Windowsへの操作はこの検証で行わない。
