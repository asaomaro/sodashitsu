# レビュー・工程変更のエージェント通知

UIでレビュー/工程を保存した後、担当assignment.nameへsodactl agent promptを送信する。担当が無ければ保存だけ行う。CLIのgetで担当を確認し、promptの--expectでpane/instance/tab/projectDir/nameを固定し、サーバの受付時/実書込み直前に再検証する。シェルは通さずargv配列、10秒上限。拡張envは継承URLを除き実際の待受URLを注入。認証tokenは追加しない。ログインキャッシュを利用する。

通知の失敗は保存を取り消さず制作詳細に結果を表示する。失敗は送信が無かったことを意味しないため自動再送しない。利用者の受信確認後に明示再送する。CLIでエージェント自身が更新した工程には通知せず、ループを避ける。通知先は自動依頼で割り当てた担当だけ。

独立点検対象: 対象の条件検証、CLIからRPCへの伝達、通知保存と失敗の扱い。最後の独立レビューを実施する。
