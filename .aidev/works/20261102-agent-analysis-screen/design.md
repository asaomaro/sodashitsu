# 設計

親のUsageAnalyticsに概要／比較／親子・ツール／エージェント分析のnavを置く。グラフのlayoutをpropsで渡し、report画面ではactive=falseとして継続timerを停止する。戻ると同条件で再開し、成功した選択条件を保持する。PC切替では停止中も条件を失効する。

UsageWorkContextは既存ConversationServiceの検証済みログの末尾256KiBを各12paneまで読み、最近の利用者2件・応答2件、未完了項目4件、cached summaryを全体16k文字の枠で収集する。ファイルの内容やコマンド等のtool結果は読出対象にしない。paneを内部IDで全収集後に再確認し、レポートJSONへはIDや検証関数を渡さない。モデルへ渡すcheckに内部verifyを合成し、準備await後・実行中も同じ対象を確認する。

モデルは現在の取り組み／使われ方／改善案／取得範囲と限界を出力する。現在作業と指定期間の履歴は別の時点と説明し、欠損・古い要約を明示する。
