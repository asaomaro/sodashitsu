This proves the installednumericdecoder shape only, not actual model accounting or production locator safety. The original fullobject comparison was false solely due to these expected omitted flags.

Projection uses only session ledger once; turns/child ledgers are not re-added. Input includes cache, so canonical noncached input subtracts both cachefields, rejecting negative/inconsistent values. Totals must be explicit safe nonnegative integers; missing is null rather than zero. Cost is only explicit positive safeticks/1e10, no pricing estimate. Incomplete usage marks partial; partial cost marks costPartial independently. primaryModelId is dominant ledger model rather than last/current parent model, so model stays null; no currentcontext/approval/effort/quota inferred.

I/O is bounded2MiB, strictUTF8/JSON, exactsessionId, before/after current kind+instance+session verifiedproof token, forget/close invalidation, before/after safeopener and descriptor/pathstat identity match. OpenedFile comes from shared exactID/root/leaf locator; no duplicate sessiondirectory scanner. Missing/partial/malformed/replaced files return null, never a fabricated0 or cachedold ledger.
