# 再起動後の残件

- [x] 実OS起動時刻と既存接続復帰を確認。
- [x] ログイン時の恒久Run登録と同じ入口からの手動ready、通常権限を確認。
- [ ] 次回ログインによる自動実行、停止状態からの新規起動。
- [x] 専用サインインサービスの異常復旧・パッケージ更新。
- [ ] initializeのclaimed/部分runtime/異常停止の原因と明示復旧。鍵や不明要求をreset/replayしない。
- [x] 生成音による実リモート仮想マイクの受信と、途中unavailableが再現しないことを確認。
- [ ] 無効状態のsr-pcデスクトップエージェントでの、今回のログイン後の通知再検証。

OSの追加再起動は行っていない。詳細と限界はverification.md。
