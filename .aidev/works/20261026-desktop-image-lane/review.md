# 独立レビュー

- 対象: `cb9ff0ba` からの画像専用接続の差分。既存のカーソル変更は対象外。
- 結果: 修正を必要とする具体的な指摘なし。
- viewer の要求と B の capability が揃ったときだけ private ticket を発行する。ticket は使い切りで、役割・親接続・認証セッション・Origin に結び付く。画像接続から入力やカーソル・動画を受け付けない。
- 親の ready をブラウザが受信した確認と、画像接続の両端の attach が揃ってから有効化する。B はそれまで最初の画像を1枚保持し、ACK は引き続き親接続を通すため、差分の基準・連番・agent の観測を共通に維持する。
- 有効化前の失敗は保持画像を親へ送って復帰し、有効化後の切断は親ごと停止する。画像 ACK の推測による再送や経路切替による重複を避ける設計と整合する。
- stop・認証失効・ticket の期限切れで接続と保持画像を回収する。画像用の送信上限は既存の画像上限に合わせ、動画用の上限を変更しない。
- 追加の relay テストには、ready/attach の barrier、secure、事前失敗、旧版への fallback、入力注入拒否、有効化後の親停止が含まれる。
- 本点検ではコードを読み、ビルド・テストの重複実行はしていない。進行中の unit/browser/build の最終結果は別途検証記録へ記載する。

## 最終追加差分の再点検

- 有効化後に画像が親接続から届いた場合は拒否する guard を確認した。カーソル・動画の既存分岐には影響せず、画像の専用経路への固定を強制する。追加の指摘なし。
- 文書は、開始前の失敗では親接続へ戻し、有効化後の失敗では再送せず共有を停止して再接続を求める実装と整合する。
