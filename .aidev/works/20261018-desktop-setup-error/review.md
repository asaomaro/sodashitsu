# 独立レビュー

review_remote_tabs（実装と別コンテキスト）が全体差分と修正差分を点検。

1. bundled helperを使用するとSODA_DESKTOP_ORIGINSが失われる: desktopOriginsFromEnvをcustom commandから分離して修正。custom envなしの回帰テスト追加。再レビュー通過。
2. 環境権限を「上限」と呼ぶ文書と保存設定優先の実装: ローカル保存した権限が環境初期値を上書きする仕様として文書・コメントを統一。再レビュー通過。
3. Web設定を接続前に取得する問題をE2Eで検出: 開いていて接続済みの場合だけ取得、再接続で再取得、旧getの結果は世代で無効化。
4. 上記再レビューでsave側の旧応答上書きを指摘: saveも世代検査し、成功/失敗とも旧応答を無効化。unmountでも世代無効化。遅延set回帰テスト追加・負の対照実施。再レビュー通過、必須問題なし。

ローカル設定RPC制限、保存の直列化、共有停止・開始待ち取消、配布物の相対パスについて必須指摘なし。
