# 所有仮想画面のOS解像度

Windowsの複数物理monitorが存在する環境でも、actual VirtualLeaseと返されたvirtualDeviceとcapture対象の完全一致がある場合に、その仮想monitorだけのOSモード変更を許可する。Bの仮想画面許可とOS解像度許可は別々に必要。通常physicalモードの単画面制限・従来Leaseは変更しない。

仮想mode適用はsupported modes/exact device/current mode/local sourceと元3秒をOS操作の前後で検査する。owned照合を含む期限を使う。owner消失時はvirtualdevice削除で終了し、DISPLAY名再利用時にphysical画面を変更し得るsize-onlyの独立復元guardianは作らない。既存virtual channelのowner/container/instance監視と最後のviewer終了時cleanupを使う。

sharedVirtualのみdisplayサイズをcohort keyと共通helper configureへ含める。共有する全窓で同じサイズを明示する。異寸法の参加は拒否し、生きた窓の解像度を勝手に変えない。UIは共有仮想画面の幅×高さ入力で参加し、単独virtualの最大解像度もowned monitorを対象にする。サインイン・管理者・physical同時captureへの権限拡大は行わない。Linux PortalのOS仮想monitorサイズは公開Portal APIの提供範囲に従う。

source/状態/共有key/OS操作はtaskcheck/cross対象。実driver/OSモード変更は試験しない。
