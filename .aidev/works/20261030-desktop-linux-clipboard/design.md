# Linux Portal text clipboard

Extend an existing RemoteDesktop Portal v2 session using Clipboard Portal v1 RequestClipboard before Start. Require explicit helper --allow-clipboard + server allowClipboard, then actual Start.clipboard_enabled and per-viewer clipboard_control generation. Clipboard-only sessions request device types0; screen-only sessions stay ScreenCast. RD combined sessions use RemoteDesktop persistence options (not ScreenCast options). No alternate OS session or permission bypass if clipboard is unavailable; ready reports actual clipboard availability.

Text MIME only, UTF16<=8192 and received UTF8<=32768. SelectionRead returns a session FD; nonblocking bounded reads recheck original UTC+monotonic ticket after native source query and select readiness, then before final NDJSON publication. One physical RPC worker remains busy through revoke until it settles, no unbounded queued retries. Source gate serializes authority and final writes; no blocking pipe waits hold gate.

SetSelection advertises only UTF8 text; SelectionTransfer obtains SelectionWrite FD, writes bounded cached human-provided text with source/owner-version and one-second deadline, then SelectionWriteDone. At most4 transfer workers, all FD paths close. Remote revoke denies remote reads but a copied text may still be pasted locally within the same live Portal session; source close zeros cached bytes. Never expose file-transfer MIME, arbitrary FD or OS operation through RPC.

Signals are pinned to same session; owner change drops cached remote data. Source change/OS permission/deadline/generation invalidate queued reads. Probe is import-only even with helper flags. Actual portal/service/display/pasteboard never used in generated checks; pipes/GIO Variant and fake D-Bus only. References: [Clipboard Portal](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.Clipboard.html), [RemoteDesktop lifecycle and clipboard grant](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.RemoteDesktop.html).
