# 合意した要件

- タブを、複数の端末・エージェントが協業する1つの作業環境とする。アプリ画面は、その作業に最適化したパースペクティブ。
- 通常のターミナルとアプリの両方で、追加ビューをタブ全体または指定作業ペインへ配置できる。利用者が呼び出す共通導線を設ける。
- 画面を切り替えても端末・プロセス・ペイン構成を保持する。
- パッケージはユーザー/PJのどちらへも導入でき、PJスコープはPJフォルダに保存する。既存の承認を引き継ぐ。
- Yukkuri Studioで進捗・成果物・確認・作業ペインを扱い、汎用ビューの配布例としてコミットグラフを用意する。
- 新規タブ作成ダイアログの入力・種類選択・PJ案内の高さ/余白を揃える。

ローカルVSCodeの既存ウィンドウ接続とsodactl skillの自動導入は、質問への説明のみで、この実装の対象には追加していない。
