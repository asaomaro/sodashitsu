# 透過時の通常テーマの視認性

透過の地に描く文字色を外側端末の明暗に合わせて補正する。選択したテーマ名・保存値は維持。明示背景と選択帯は維持し、既定前景は明示背景上でも必要時に補正する。反転表示の空白も同じ色で補正。OSC11による明暗変更で描画を無効化。

検証: 全19テーマ×外側の明暗のコントラスト、既存の明示配色維持、OSC11反映、描画された反転帯。修正を外して回帰テストが失敗することを確認し、元のバイト列に復元。生ログは negative-contrast.txt。

独立レビュー: review_bubble_resize。反転空白の指摘を修正し再レビューで必須指摘なし。

最終検証: pnpm build / pnpm typecheck 通過。TUI全84ファイル775件通過。
