# 会話操作の追加

数十ファイルに跨るため次の独立した機能群に分けて実装・検証する。既存TabViewsの利用者変更は保持。

- [x] 会話記録を安全に読む共通サービス、送信メッセージと会話表示、過去セッションの一覧・再開（脆弱なファイル境界とプロトコルを独立点検）
- [x] 設定可能なペインヘッダー操作と対応エージェントの能力表（compact/clear/usage/承認/fork）。未対応操作は表示・実行しない
- [x] 独立した要約実行とエージェント/モデル/要約セッションの設定、結果ウィンドウ（プロセス・会話の分離を独立点検）
- [x] 通知の対応状況をサーバで共有しWeb/TUIへ同期。既存TUI内トースト・通知一覧を利用（状態保存・再接続・共有を独立点検）
- [x] 利用者向け文書、関連テスト・E2E・全体チェック、差分全体の独立レビュー

btwは継続できる別ペインの相談として既存forkを利用し、ヘッダーに導線を提供する。
会話JSONLとCLIのresume一覧は同じ記録が元だが、CLI独自の索引・アーカイブ/フィルタと完全一致するとは表示しない。
端末のスクロールバックに残っていればメッセージへ移動し、無い場合は会話記録ウィンドウの正確な位置を表示する。

- [x] プラグインをworkspace/tab指定でCLIから操作し構造化結果を返す。skill/MCPはこの共通APIを使う。MCPサーバー本体は必須ではなく今回の実装範囲に含めない。

- [x] tabView.mobileDisplayによる専用モバイル主画面、旧タブ反映、保存復元、Commit Graph例、ask-form実ブラウザ検証
- [x] WebのNerd Font補完（通常文字維持・ローカル配布・遅延ロード再描画）、TUIのBMP/補助領域保持確認
