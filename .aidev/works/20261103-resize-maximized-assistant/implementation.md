# 最大化中の枠リサイズ

会話・設定・ツール・操舵室ビューの最大化時もリサイズ開始を許可する。実際にboundsが変わる時点で最大化/復元の記録を消し、変更後のboundsをそのまま適用して通常状態を通知。従来の元サイズへの復帰を通さず、リサイズ中に飛ばないようにする。押下だけ・移動量0・作業領域でclampされ変化しない操作では最大化を維持。

会話の記憶サイズは通常状態の時だけ保存し、最大化中のno-opで通常サイズが上書きされないようにする。会話の右/下固定、一般窓の8方向、トークン・送信元・寿命・非表示時の制限は維持。継続ドラッグと、リサイズ後の最大化→復元は変更したサイズに戻る。

検証: host52件、アシスタント全30ファイル244件通過。新規に4種類それぞれで最大化→動かさず押下/移動0→実リサイズ→状態通知→継続リサイズ→最大化/復元を検証。修正前main.tsへ一時的に戻すと新規回帰テストが既存の最大化リサイズ拒否で失敗（negative-resize.txt）。ソースをバイト一致で復元。

独立レビュー: review_resource_monitorがbounds適用順・状態解除・継続gesture・4種類のテストを点検し必須指摘なし。
