# 外部接続の画面操作

要望: 外部Sodashitsu追加と操作委譲を画面から行う。

既存のコード交換フォームを維持し上部へ呼出ボタンを追加する。欠けていたSSH登録フォームと認証済みmachine.addを追加。Web/モバイルとTUIのローカル管理接続に固定する。SSH鍵の設定と相手Sodashitsu起動は事前条件。入力は既存のtarget/session/label規則で検査し、招待・管理と同じqueueで保存。登録した後に既存managerで接続し、失敗は一覧に表示する。

対象外: SSH認証情報の入力保存、SSHやOSのセットアップ、公開URLの自動発行、URLだけで認証を省く新しい直結方式。

点検: 保存・プロトコル・安全は独立点検対象。全差分と修正は独立レビュー。文書・見た目は全体で確認。
