# 制作からエージェントへ自動依頼

- 制作詳細でエージェント選択と［新しい作業ペインで依頼］。同じタブに新しい端末を分割し、PJ cwdで対話エージェントを初期指示付き起動する。
- 既存agent.startとCLIの初期プロンプト引数を利用。まずClaude Code/Codexを対応対象とし、サーバPATHで起動可能か判定する。任意コマンド/引数の入力は提供しない。
- 汎用拡張APIにtask.kinds/task.startを追加。agent-start許可がある稼働中の拡張だけ。対象は拡張自身が提供するアプリ/ビューの同じタブ、PJ内の通常taskファイルのみ。毎await後に範囲と稼働を再確認する。
- ペイン生成後、シェル準備を上限付きで待ち、生成後に失敗したペインは調査のため残す（既に利用者が入力している可能性もある）。失敗の表示にペインIDを含め、作業画面で確認できる。
- 制作台帳に選んだkind/依頼先pane/起動指示済み/失敗を保存。起動指示済みは起動完了と区別。taskファイル単位で同じ稼働ペインへの重複依頼を防ぐ。
- 既存手動task生成も維持。パッケージ0.4として配布し、導入済みPJへ更新。新しい許可でプロジェクト承認が必要になる。

点検対象: task APIの範囲/ライフサイクル/並行/cleanupを独立taskcheck。最終レビューはサーバとプラグインUIの2単位。ブラウザE2Eは偽エージェントを実PT Yで起動し、ブラウザ受信の出力と制作UI/ペインを観測する。
