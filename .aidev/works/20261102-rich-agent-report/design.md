# 設計

現在paneの情報は状況一覧へ集約。旧種類別棒グラフ・一時的な累計観測・UsageHistoryPanelを削除し、保存済みモデル／effort別金額を比較タブのUsageAccountCostへ移す。旧usage_history RPCは互換性のため残す。

生成先へJSON形式を指示し、件数・文字数・優先度をZodで検証する。構造化結果は可読textも併記。非構造化結果は旧見出しを4区画へ適応し、全文は折り畳みで保持する。数値指標はサーバが生成入力の集計から添付し、モデルに算出させない。USDは期間指定なしのアカウント累計と表示する。

Vueの通常補間とエスケープした静的HTMLで表示し、モデルのHTMLを実行しない。保存HTMLに外部資源・スクリプトを含めず、CSPを付与。明暗・狭幅・印刷に対応する。生成先への作業抜粋の開示と明示生成、既存の認証・対象検査は維持する。
