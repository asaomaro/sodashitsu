# フッター設定の導線と表示内容

- 一般設定はフッターの表示切替だけを残す。
- Web・モバイル・端末版とも左端のメニューボタンから専用設定ウィンドウを開く。
- CPU・OSメモリ・サーバーRSSの割合はstatusline共通グラフの表示有無・4パターンを選べる。
- 全ワークスペースのエージェント総数とworking/idle/blocked/unknown別件数を選べる。仮想ペイン・過去セッション・内部サブエージェントは含めない。
- 全項目を外しても設定ボタンとフッター1行を保持する。旧設定を維持し、追加グラフは非表示を既定にする。
- 表示設定はWeb・端末で共有し、実OS情報のキャッシュとエージェント件数の最新集計は分離する。
